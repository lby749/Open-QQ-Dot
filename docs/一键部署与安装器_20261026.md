# 一键部署与安装器界面（2026-10-26）

## 目标

安装器负责从零到可启动：校验安装包 → 复制程序 → 准备独立 Python → 安装依赖 → 创建快捷方式 → 启动。更新时保留好友、聊天记录、模型设置与登录状态。

## 界面

`installer_ui.py` 使用标准库 Tkinter 自绘（安装器运行时还没有 PySide6），与主程序一致的深蓝视觉：

- 渐变页头、应用图标、版本与「本地运行/数据留在自己电脑」说明；
- 安装位置（默认 `%LOCALAPPDATA%\Programs\OpenQQDot`；检测到便携版 `OpenQQDot\friends.json` 时优先便携目录）；
- 选项：桌面快捷方式、开机启动、安装后立即启动；
- 右侧四步时间线（检查环境 / 安装程序文件 / 配置运行环境 / 完成）、进度条与状态；
- 「显示安装日志」可展开实时日志；完成后按钮变为「启动 Open QQ Dot」；
- `python -X utf8 installer_ui.py --preview` 只预览界面，不写文件。

## 一键部署流程

`windows_installer.run_install`：

1. 校验 `application.zip` 的 SHA-256（与 `application.sha256` 一致）。
2. `preflight`：目录可写、磁盘 ≥2GB、安装包/uv 齐全、是否正在运行、是否系统目录。
3. `install_source` 逐项校验路径与敏感文件，先备份被覆盖的源文件到 `installation-backup/`，再原子替换。
4. `install_runtime` 把 `runtime.zip`（或安装器旁的 `qq-runtime/`）解压/复制到目标 `qq-runtime/`；这是内置 QQ 协议运行时，首次安装后即可直接连接。未携带运行时只给出提示，程序仍可启动。
5. 复制 `.bootstrap/uv.exe`；不存在 `.venv` 时用 uv 创建 Python 3.13。
6. `uv pip install -r requirements-ui.txt`；失败自动重试一次，再验证实际导入（PySide6、qfluentwidgets、PIL、psutil、websockets、jsonschema、numpy、pypdf、ijson、qrcode）。
7. 写入 `.openqqdot-install.json`（版本、安装包哈希、时间）。
8. 创建桌面/开始菜单快捷方式（失败只提示，不阻断）；可选 HKCU 开机启动。
9. 启动 `pythonw launcher.py`。程序启动后自动打开「QQ 直连」页：有快速登录记录直接免扫码登录，没有则显示二维码；登录成功后自动启动消息桥接。再点「从 QQ 导入好友」即可勾选当前账号好友，完成从安装到可聊天的整条链路。

任何一步失败都可直接重试；已复制的文件与 `installation-backup/` 保留，不会删除朋友或登录数据。

## 命令行

```powershell
# 静默安装/更新
"Open QQ Dot Setup.exe" --silent --destination "D:\Apps\OpenQQDot"

# 源码方式
python -X utf8 windows_installer.py --silent --destination "D:\Apps\OpenQQDot" --no-launch
python -X utf8 windows_installer.py --preview
```

`--no-shortcut` 可跳过快捷方式；`--no-launch` 只安装不启动。

## 源码环境

`setup_environment.ps1` 同样改进为一键：

- 优先使用 uv，创建 Python 3.13（或本机 3.11+）；
- 安装 `requirements-ui.txt`；
- 验证真实导入；
- 调用 `dotlink_setup.py` 准备 DotLink 自己的本地配置（`dotlink/`，独立登录）；
- 输出启动命令。

## 构建

`tools/build_windows_installer.py` 现在会：

- 把 `installer_ui.py` 作为隐藏导入，并把 `assets/app-icon.png|ico` 打进安装器；
- 从 `napcat/runtime` 生成 `runtime.zip` 与 `runtime.sha256`（默认包含；构建时加 `--without-runtime` 可跳过）；
- 把运行时一并放进安装器，安装后即可连接 QQ。

## 边界

- 安装器不附带 Python、模型权重或 QQ 登录态；Python 由 uv 在本机准备，QQ 登录由 DotLink 在 `dotlink/qq-data` 中单独完成。
- 首次 QQ 登录仍需一次扫码（或本机已有快速登录记录）；安装器不绕过 QQ 风控。
- 不支持在安装器内迁移其他平台对话；安装完成后在「设置与工具 → 迁移助手」进行。
- 快捷方式/开机启动是当前用户级，不请求管理员权限；安装到 Program Files 仍可能需要管理员。
- `runtime.zip` 约 300MB，因此完整安装器体积较大；不需要内置运行时的分发可用 `--without-runtime`。
