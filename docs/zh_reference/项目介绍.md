# Open QQ Dot

<img src="assets/app-icon.png" width="112" alt="Open QQ Dot">

**一个部署在你本地电脑上的 Dot，可以接入各家的模型，也可以模仿不同的说话风格。**

Open QQ Dot 希望把 AI 助手放进你日常使用的 QQ：让它记住聊天中的事情，用你设定的方式说话，并在获得授权后，使用你自己的电脑完成文件和程序任务。

你可以自己选择模型，给不同好友设置不同的人设、记忆和权限，再通过桌面小屋或手机小屋管理它。

这是一个独立开源项目，以 Dot 式个人助手为产品方向，与 OpenAI 官方产品无隶属关系。

## 你的电脑，就是它的工作环境

Open QQ Dot 在你的 Windows 电脑上部署。聊天记录、记忆库、风格模板和任务文件由本机保存，电脑工具也在这台电脑上执行，不需要另外准备云电脑。

本地部署不等于必须使用本地大模型。你可以通过 CLI 或 API 使用云端模型，也可以按需接入本地模型或本地兼容服务。使用云端模型时，完成请求所需的上下文会发往你选择的服务商。

电脑和程序在线时，助手才能继续处理消息和执行任务；关机后不会在另一台云电脑上继续运行。

## 模型由你选

当前提供 Codex CLI、Claude CLI、Antigravity CLI 和通用 API 入口，各自有独立的配置界面。

API 支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 兼容协议，可以保存多套接口地址、模型和密钥。采用这些协议的不同服务商可以按需接入，具体能力取决于所选模型与接口。

接口分成三类：

| 类型 | 用来做什么 |
|---|---|
| 模型API | 聊天、内容生成和需要模型推理的工作 |
| 检索API | 把内容转成向量、检索记忆，以及对候选结果重排 |
| 功能API | 连接你配置的查询或业务 HTTP 接口，作为助手的工具 |

每个服务使用自己的账号或密钥。模型可以更换，已经保存的好友记忆和风格配置可以继续使用。

## 让它有不同的说话方式

助手的说话方式可以按好友分别设置：简洁直接、耐心解释、活泼口语，或者你自定义的其他风格。

除了手写人设，还可以从你有权使用的聊天导出文件中，整理某个说话人的回复示例，生成风格模板。模板结合句子长短、消息条数、语气词、笑声、表情和口头禅等特征，影响后续回复的表达方式。

例如，同样回应“今天好累”，你可以设定不同的表达倾向：

| 风格 | 原创示例，仅用于说明 |
|---|---|
| 简短直接 | 先歇会儿，剩下的明天再弄。 |
| 温和细致 | 今天忙了很久吗？先坐下来缓缓，喝点水。 |
| 活泼口语 | 快躺！今天的电量已经见底了哈哈。 |

你可以生成、导入、导出模板，再应用到当前好友；主动聊天的开场方式也可以单独设置。模仿的是表达习惯，效果受样本和模型影响，不保证与某个人完全一致。

模板生成支持程序统计、可选本地模型和云端分析。不下载本地模型时，仍可保留回复示例和可统计的风格特征。

## 不止一问一答

Open QQ Dot 保留了长期记忆、偏好与话题资料、聊天记录、心情记录、表情收藏、主动聊天、续话和时段关心等功能。

不同好友使用独立的上下文和设置。你可以让它针对不同的交流对象采用不同的表达方式，并在桌面小屋中查看和管理这些内容。手机小屋网页也保留在项目中，方便通过手机查看和调整已有设置。

## 电脑能力，由你逐位授权

每位好友都有独立的“本地电脑工作台”开关，默认关闭。开启后，助手可以在该好友的专用工作目录中列出、读取和写入文本文件，并在本机打开网页。

执行 PowerShell 命令还需要单独开启命令权限。命令具有当前 Windows 用户的系统权限，工作目录不构成系统沙箱，因此应按自己的使用场景决定向哪些好友开放。

当前已提供文件和命令工具。完整的视觉桌面操作、浏览器多步自动化和通用长任务调度仍属于后续方向，详见 [功能范围](Dot功能对照.md)。

## 轻量开始，按需增加本地模型

发行包不附带模型权重，也不自动下载模型。默认通过程序规则、关键词和 BM25 等方式承担基础分类与检索；需要更强的语义能力时，可以另配检索 API 或下载适合自己电脑的小模型。

你不必为了开始使用聊天和小屋管理功能，先部署一整套本地大模型。在线生成仍然需要可用的 CLI、API 或自行配置的本地推理服务。

## 一段可以直接用于发布的介绍

> Open QQ Dot 是一个部署在你本地电脑上的 Dot 式 AI 助手。它以 QQ 为聊天入口，可以接入多家模型服务，通过人设和聊天风格模板模仿不同的说话方式，并保留长期记忆、主动聊天和手机小屋等功能。获得你的授权后，它还能使用本机文件和命令工具。模型自己选，风格自己定，电脑权限按好友分别管理。
