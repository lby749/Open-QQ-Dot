# 模型推荐与降级说明

发行包不含任何本地模型权重，也不会自动下载。最省事的方式是保留默认的“不使用本地模型”，先配置一种云端 CLI 或聊天 API。

## 功能如何保留

| 功能 | 不安装本地模型时 | 能力边界 |
|---|---|---|
| 正常聊天、看图、主动聊天、续话、时段关心 | 使用所选云端模型 | 看图取决于所选模型；云端不可用时不编造回复 |
| 记录、心情、长期记忆管理 | 保留程序逻辑和本机数据库 | 首次没有原来的个人数据 |
| 消息/场景分类 | 程序规则 | 不等同于语义模型；拿不准的分类保留待复核 |
| 记忆、资料和表情匹配 | 关键词/BM25；检索 API 可选 | 不安装/不配置语义模型时，同义改写召回会减弱 |
| 向量检索与重排 | 可选独立的远程或本机 API | 未配置、超时或错误时返回程序检索 |
| 人格模板 | 默认程序统计，保留真实示例与说话习惯 | 不把统计冒充人格推断；可另选云端分析 |
| 摘要、兴趣提取和后台资料整理 | 继续由云端处理 | 联网整理按现有路径使用 Codex；选 Claude/Antigravity 时可用对应 CLI；普通 API 无内置搜索 |
| Codex 额度耗尽时的本地聊天兜底 | 不提供无模型的自由生成 | 暂停并显示原因；可由操作者切换已配置的其他来源 |

## 推荐的可选检索模型

以下是标准 Transformers 接口的配置候选与预设，不是逐个下载测速的承诺。CPU 也可运行；速度取决于机器、文本长度和批量。

| 用途 | 官方模型 | 设置 | 选择理由 |
|---|---|---|---|
| 中文向量检索，优先尝试 | [BAAI/bge-small-zh-v1.5](https://huggingface.co/BAAI/bge-small-zh-v1.5) | 512维，CLS；查询前缀由预设填写 | 中文检索的 small 选项 |
| 多语向量检索 | [intfloat/multilingual-e5-small](https://huggingface.co/intfloat/multilingual-e5-small) | 384维，mean；查询 `query: `，文档 `passage: ` | 不局限于中文，须保留前缀 |
| 多语句子相似度 | [paraphrase-multilingual-MiniLM-L12-v2](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2) | 384维，mean | 多语、小型编码器 |
| 多语重排 | [mmarco-mMiniLMv2-L12-H384-v1](https://huggingface.co/cross-encoder/mmarco-mMiniLMv2-L12-H384-v1) | 分类头 cross-encoder | 多语重排候选 |
| 中文/英文重排备选 | [BAAI/bge-reranker-base](https://huggingface.co/BAAI/bge-reranker-base) | 分类头 cross-encoder | 体积高于 MiniLM 选项，非最轻量 |
| 更轻的英文重排 | [ms-marco-MiniLM-L6-v2](https://huggingface.co/cross-encoder/ms-marco-MiniLM-L6-v2) | 分类头 cross-encoder | 英文候选，不把它当中文优先方案 |

本地直接适配标准 `AutoModel` 的 CLS/mean 向量和 `AutoModelForSequenceClassification` 的单分数/二分类重排。需要执行自定义模型代码、特殊推理后端、GGUF 或 ONNX 的模型，可通过兼容的本机服务 API 接入；不保证所有模型架构直接加载。

## 自行安装

1. 从上表官方仓库下载完整模型文件，阅读该模型自己的许可证。向量与重排是两种不同用途，不能互换。
2. 如选择本地目录加载，安装 `requirements-local-models.txt`。这里只安装推理库，不下载模型。
3. 在“模型设置 → API → 检索API”选择“本地小模型目录”，选预设和目录，默认设备 auto（CUDA → MPS → CPU）；可手动选 cuda、mps、cpu。按模型卡核对维度、池化和前缀。
4. 开启全局“启用已安装的本地模型”，再开启要使用的向量/重排模型并保存。
5. 模型切换会区分缓存版本与维度。常用记忆/资料/表情向量缓存重建；其他旧结构化索引若不兼容会拒绝复用并降级，须重新构建索引。

本地加载使用 `local_files_only=True`、`trust_remote_code=False`。不会因缺少文件自行访问模型仓库。文件损坏、维度或配置错误不会触发设备回退，错误会向上报告；上层检索仍可能按已有规则返回程序检索结果，不能据此认为模型已成功运行。设备回退仅处理明确的后端兼容或资源错误，且只在auto模式启用。详见[本地推理跨平台说明](本地推理跨平台说明.md)。

若使用 API，向量接口按 OpenAI `/embeddings` 格式，重排按 Cohere/Jina `/rerank` 格式。可填本机 HTTP 服务地址，密钥可以独立保存；无鉴权本机服务可不填 Key。不同模型的相似度与重排分数分布不同，实际召回质量仍需用自己的脱敏样本评估。

本地生成式聊天兜底仍保留原后端，需另行准备相应 llama-server、GGUF 和 `build/message-classifier-runtime/runtime.json`；格式示例在 `examples/local-chat-runtime.example.json`，它不是模型文件。当前推荐清单侧重轻量检索/重排，不强制下载原 9B 模型。
