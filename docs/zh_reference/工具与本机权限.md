# 工具与本机权限

工具接入范围是项目实际提供的工具。不会复制操作者 ChatGPT/Codex 桌面插件的登录状态，也不会把未安装的外部服务当作可用工具。

|---|---|---|---|---|
| `search_friend_memory` / `search_topic_library` / `get_today_chat` | MCP | MCP | 程序工具循环 | function calling |
| `phone_now` / `phone_usage_today` / `phone_screen_text` / `app_history` / `set_history_apps` | MCP | MCP | 程序工具循环 | function calling |
| 当前好友启用的 `api_*` 功能接口 | 同一 MCP 工具目录 | 同一 MCP 工具目录 | 程序工具循环 | function calling |
| 当前好友授权的 `desk_*` 电脑工具 | 同一 MCP 工具目录 | 同一 MCP 工具目录 | 程序工具循环 | function calling |
| 联网搜索/网页读取 | 原生联网工具 | `WebSearch` + `WebFetch` | `search_web` + `read_url_content` | 须另配合适的功能API |

每个后端继续执行原有联网额度与好友隔离规则。无工具的后台摘要/纯文本提取不暴露电脑工具。未完成的 Android 客户端未随包提供，手机工具实际可用性取决于已有设备配对。

## 本地电脑与项目权限

- **项目文件夹绑定**：支持在界面中指定或浏览绑定本地项目文件夹（如 D:\Projects\Demo），CLI 将以此目录作为工作根目录进行编程开发（留空则默认使用 workspaces/<QQ>/）。
- **对整个电脑的访问开关**：开启后解除目录边界，允许全盘文件读写；关闭时严格限定在绑定的项目文件夹内，防止越界。
- **操作权限（只读/可读写）**：只读模式下仅供查看代码与项目结构，禁止修改文件与写代码；可读写模式允许完整代码编辑与创建。
- **命令执行与审批模式**：
  - **Codex**：开启命令时动态启用 eatures.shell_tool 与 eatures.unified_exec，沙箱根据读写和全盘范围自动映射为 dangerFullAccess / workspaceWrite /

  - **Claude**：开启命令时解锁全部原生工具（Bash, Edit, Write, Read, Glob, Grep），只读模式限缩为只读工具，审批模式支持 dontAsk 与 sk。
  - **Antigravity**：开启命令时动态放行命令与写文件策略（unrestricted / on），只读模式保持拦截。
- desk_list_files / desk_read_file / desk_write_file / desk_open_url / desk_run_command：由好友配置的权限统一管控。

命令的系统权限属于当前 Windows 用户。电脑权限仅由本机管理界面配置，手机网页不能提升权限。

## 功能 API

用 `api_` 开头的唯一工具名，写清用途，填写固定 GET/POST 地址及参数 JSON Schema，可选 Bearer 或 X-API-Key。每个接口保存自己的加密密钥；地址和参数不要直接填入密钥。POST 固定参数与模型提供的参数合并后作为 JSON 请求体。

保存后，启用的功能会自动出现在各 CLI 的好友工具目录中。HTTP 调用超时20秒、响应最多256 KiB，参数须通过 Schema 校验，不跟随重定向。响应标记为外部数据，不执行其中的指令。

原生 shell、任意文件修改、全局 MCP、桌面插件和多代理等能力没有按账号全量放开。需要执行电脑任务时走上述按好友授权的明确入口；完整浏览器自动化/桌面视觉控制仍需要额外适配。

官方协议参考：[Codex App Server](https://developers.openai.com/codex/app-server)。Claude/Antigravity 的工具名称和开关还取决于用户安装的 CLI 版本与账号能力。
