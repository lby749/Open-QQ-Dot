# 长期目标使用说明

在好友小屋打开“任务看板与审批中心”，可看到“长期目标”和“新建目标”。继续使用该好友原先配置的模型、工作目录和电脑工具开关。

## 创建与执行

1. 在“新建目标”填写目标、授权范围和总体验收条件。
2. 可以自己填写阶段计划，每行使用 `标题 | 执行说明`，再选择任务类型；也可点击“先让 AI 生成阶段草案”。
3. AI 草案会出现在“任务”列表，只生成计划。阅读完整草案后，点击“确认计划并创建目标”才创建执行阶段。
4. 目标阶段按顺序进入现有后台任务引擎。文件、代码等使用原验收器；需要人工判断的阶段在任务列表确认。
5. “长期目标”中查看已验收进度、阶段结果、产物路径和历史记录。全部阶段通过后，按总体验收条件填写结论，目标才正式完成。

程序必须正在运行且后台任务 Worker 已启动。关闭电脑后不执行。后台未启动时只入队保存，不会丢失计划。

## 控制与预算

- 可暂停、恢复或终止目标。用户单独暂停的阶段不会随目标恢复；失败阶段先在任务列表处理，再恢复目标。
- 重启不会重跑已完成阶段；正在执行时中断的阶段保留检查点，按原任务机制等待人工恢复。
- 模型调用次数与 Token 预算平均分给阶段，余额暂不自动转移。Token 分实际/估算统计，无法保证输出精确不超估。
- AI 规划另计预算：最多2次模型调用、8000 Token。执行阶段采用创建目标时指定的预算。
- scope 说明不会扩大工具权限。实际文件/命令权限仍由该好友的电脑工具设置执行；自然语言范围不是新增的系统沙箱。
- 规划目前支持 Codex、Claude、模型 API；DSH/Antigravity 可手动填写阶段计划，原普通任务能力不受此限制影响。

## 当前未完成

自动周期巡检、目标修订、结果驱动重新规划、真实 QQ/手机联调还在开发。目标事件可在重启后查看，实时通知队列尚不持久化。API 可设置截止时间，过期暂停；延期入口尚待实现。不要将当前有限阶段目标理解为已经完成全部长期自主能力。
