# OpenCode 接入修复（2026-10-26）

用户报「open code 接入失败」。桌面端「智能体与工具 → OpenCode → 检测接入」报的是
`OpenCode request failed: URLError`，也就是根本没连上。

## 实测到的真实情况

| 项 | 实际 |
|---|---|
| 已装版本 | OpenCode **2.0.32**（桌面版，`%LOCALAPPDATA%\Programs\@opencodedesktop`） |
| 服务形态 | `opencode-cli serve --service`，后台服务，**端口每次随机**（本次 `http://127.0.0.1:45278`） |
| 认证 | HTTP Basic，用户名 `opencode`，口令持久化在 `~/.config/opencode/service.json` |
| API | 全部在 `/api/*`；文档里的 v1 路径 `/global/health`、`/path`、`/session` 在 v2 里**不存在** |
| 根路径 | 返回的是 Web 界面 HTML，不是 JSON |

原来的适配器写死了 `http://127.0.0.1:4096` 和 v1 路径，这两点都不成立，所以必然失败。

## 改了什么

1. **自动发现**（`agent_tool_adapters.opencode_discovery`）：
   - 地址：调用 `opencode service status`（PATH 或桌面版自带的 `opencode-cli.exe`）取当前监听地址；
   - 口令：读 `~/.config/opencode/service.json`；
   - 显式 `url` 与 `OPENCODE_SERVER_PASSWORD` 仍然优先，且仍然只允许 `http://127.0.0.1:<端口>`。
2. **协议自适应**：先试 `/api/info`（v2，返回版本号），不行再回落 v1 `/global/health`。
3. **执行走 v2**：
   - `POST /api/session` 带 `location.directory = 授权工作目录`，会话自己绑定目录，
     不再要求「桌面版当前打开的目录正好等于任务目录」；
   - `POST /api/session/{id}/prompt {text}`；
   - 轮询 `GET /api/session/{id}/message`，直到出现 `idle`，再从 `assistant` 消息里取文本。
4. **错误不再被吞**：provider 返回的 `error.message` 会进入异常信息（截断 300 字），
   而不是变成「OpenCode did not return a completed text response」。
5. **模型与思考档位**（用户要求「读取模型、切换思考强度、切换模型」要和别的 CLI 卡片一致）：
   - 卡片不再用文本框，改为「模型」下拉 + 「提取可用模型」按钮 + 「思考档位」下拉，
     与 Codex / Claude Code / Antigravity 三张卡片同一套交互；
   - 「提取可用模型」调用 `GET /api/model`，列出该账号实际可用的模型（实测 71 个）；
   - 思考档位取自所选模型自带的 `variants`（如 `low / medium / high / xhigh / max`），
     切换模型时按该模型重建，选「默认」则用 OpenCode 自己的档位；
   - 保存为 `agent_adapters.opencode.model = "provider/模型"` 与 `.variant`，任务创建会话时写进 `model` 字段。

## 实测结果

- 接入检测：**通过** —— `服务连接正常（OpenCode 2.0.32，http://127.0.0.1:45278）；服务工作目录：C:\Users\Administrator`
- 提取可用模型：**通过** —— 读取到 71 个模型；选中 `opencode-go/kimi-k3.1-pro` 后思考档位变为
  `默认 / low / high / max`（该模型自带的档位）。
- 真实任务：请求到达 OpenCode 并返回了模型侧的原因，而不是连接错误：
  - 默认模型 `opencode-go/iceman-contributor-free`：
    `This Go model trains on request data. Allow paid endpoints that train on request data in your workspace's Privacy settings to use it.`
  - 换免费模型 `opencode/flint-40b-free`：
    `Free usage limit reached. ... subscribe to OpenCode Go to keep going.`

**结论：程序侧已经连通，能否真正跑任务取决于 OpenCode 账号本身**——需要在 OpenCode 里换一个可用模型，
或在工作区隐私设置里允许该类端点，或订阅 OpenCode Go。这些是账号操作，未代替用户执行。
