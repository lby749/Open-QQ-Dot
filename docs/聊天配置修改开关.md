# 聊天配置修改开关

## 行为

好友级设置：

```json
"chat_config_edits": false
```

默认关闭。

- 关闭：聊天/Agent 不允许修改好友配置、模型、提示词、权限
- 开启：网页 Agent 的提示词允许配置修改；工作区命令也不再被配置关键词拦截
- 桌面/手机设置页由你手动修改，不受此开关限制

## 入口

模型页 →「本地电脑工作台与项目权限」→

> 允许聊天/Agent 修改配置（模型、提示词、权限等）

保存后只对当前好友生效。

## 强制执行点

1. `web_agent.py`：关闭时提示词明确禁止修改配置
2. `workspace_tools.py`：关闭时 `desk_run_command` 命中配置 API/文件名直接拒绝
3. `tool_registry.validate_path_in_bounds`：任何权限下都拒绝 `friend.json`、`friends.json`、`house_web.local.json` 等
4. 完全访问仍不能通过文件工具读这些秘密

## 注意

原生 CLI Agent 自带 shell，拥有完全访问时可以绕过应用层提示词；这时只能靠独立低权限 Windows 账户或 ACL 隔离。
