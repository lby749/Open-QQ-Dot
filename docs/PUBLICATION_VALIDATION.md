# BETA.3 公开修订验证

后续本地安装器候选修订的最新检查见 [Windows 零依赖安装复核](INSTALLER_ACCEPTANCE_20261112.md)。该候选仍有沙箱快速登录及外网验证阻碍，尚未覆盖公开发行附件；以下是此前公开修订的记录。

本次公开修订重新打包 Windows 安装器、绿色包和完整源码；两个蓝色 APK 的字节与先前通过签名、启动及覆盖保留检查的版本相同。

## 修改与实际结果

- 修正源码打包只读取根级忽略项时遗漏第三方 `target` 缓存的问题：共同打包过滤和独立归档核查均排除 `target` 与 `.class`，保留 Java 源码和必要的 Gradle 包装器。
- 修正云端界面测试漏装 `qfluentwidgets`，使用与安装器相同的基础依赖加单独 Fluent 安装步骤。
- 修正本地推理检查漏装 pytest，以及旧回归入口只收集 unittest、没有使用 pytest 隔离夹具的问题。独立进程先复现混合测试及夹具失效，再验证两个测试样式均实际执行。
- 修正两处 Python 3.11 不支持的嵌套字符串表达式；保持原例句和 HTML 输出。真实 Python 3.11.15 对 637 个公开 Python 文件编译通过。
- 最终去重后的定向套件：**105 项通过**，涵盖人设、源码过滤、测试入口、安装器、启动准备及本地推理策略；不是把不同轮次数量相加。
- 新安装器在本机独立新应用目录完成实际安装和覆盖修复，退出码均为 0。安装的 406 个文件逐项匹配最终应用负载；Qt、Fluent、SQLite 等实际导入成功，合成数据标记在修复后保留。

## 证据边界

新安装检查所在宿主机已有 Python，不能称为零依赖云机。原 BETA.3 独立 Windows Sandbox 的 2475 项通过、25 项跳过及真实模型/QQ 记录属于对应历史快照，详见 [原 Windows 报告](BETA3_VALIDATION.md)；不把它改写成这次新安装器已重新完成同一轮全量。

本次后续 GitHub Windows 源码全量结果以[工作流记录](https://github.com/lby749/Open-QQ-Dot/actions)和发行说明中列出的实际完成结果为准。CI 中安装了开发依赖，不能冒充没有 Python 的空白系统。macOS 取消项、实体手机及连续多日运行等仍未因此获得通过结论。

原始失败保留；私人构建日志、账号资料、签名私钥、登录态、原始聊天和工作区不进入公开源码或附件。本轮没有使用 Claude，没有改变实际 QQ 登录。
