# 任务提示词去重与会话续接（2026-10-25）

本轮处理聊天、工作台任务、长期目标阶段、跨智能体子任务、研究、浏览器规划和工具回合中的无效重复。复用现有任务 Worker、权限、预算与验收器，没有另建任务引擎，也没有删除独立验收来节省请求。

## 修复的重复路径

1. **聊天异常导致全文重发**：原先只要续接出现任何异常，就清掉会话记录再完整请求一次。现在只有明确的“会话不存在”才允许重建；额度、认证、网络、超时和取消不会走这条全文重发路径。
2. **普通任务和验证重试新建会话**：原先多次 `call_single_agent` 没有复用返回的会话编号，且任务内的 Codex 入口直接丢弃了传入的线程编号。现在按任务、好友、项目、引擎和子任务角色绑定可信会话；未改变的长任务只引用已发送上下文，并追加本轮验证反馈。
3. **原生 Codex App Server 重试新建线程**：复用同一客户端已绑定归属的线程，校验返回编号，避免重复创建线程和重新发送任务。不会把检查点里的任意线程编号当作授权。
4. **多层嵌套重试**：任务由 TaskManager 控制重试，内部智能体调用不再额外重试一层。网络/模型超时等结果不明时暂停并保留检查点；取消异常不再被包装成可重试错误。
5. **Antigravity 工具回合重复全文**：每个工具回合原先新建会话，再附上整个任务、工具定义与累计结果。现在使用 CLI 返回的实际 `conversation_id` 和 `--conversation`，保留同一临时智能体，后续只补发新增工具结果。旧版本或未提供会话编号时保留完整上下文，不发送无依据的引用；续接返回错误编号时停止。
6. **研究重试重新规划和检索**：公开检索问题与文献取得后立即保存检查点，分析阶段失败后复用已完成步骤；研究目标变化时清掉相关缓存。真正的分析重试携带失败原因，不原样盲重做。
7. **浏览器规划包含整页 HTML**：规划请求只提交 URL、标题、正文、可用控件和操作历史，不再同时提交巨大 HTML 与重复页面正文。实际浏览器执行、截图、登录/支付等拦截和独立验收保持原有路径。
8. **跨智能体包装重复原始任务**：移除交接说明和汇总分配条目中与已给出的完整任务逐字相同的重复内容，保留真正的子任务要求和成果正文。不同智能体首次接手仍取得完整任务。

## 保留上下文的条件

- 任务会话的可信绑定只保存在当前 TaskManager 进程中，检查点不能伪造它；任务结束即清理。新进程、不同好友/项目/角色/引擎、权限或配置变化，以及基础任务改写，都不能误用旧上下文。
- Codex 通过已有日志检查压缩状态；Claude 通过成功返回流里的 `compact_boundary` 事件维护当前进程可确认的压缩计数。参考[官方会话说明](https://code.claude.com/docs/en/agent-sdk/sessions)与[官方代理循环说明](https://code.claude.com/docs/en/agent-sdk/agent-loop)。状态未知时保守补发，不能假装模型记得未确认的内容。
- 已知发生压缩后重新同步上下文，连续引用达到上限后也补发完整任务；短任务保留原文，避免引用包装反而更长。
- 聊天模块只与“当前生效版本”比较，不再把“历史上曾发送过”当成“现在仍生效”。例如情绪 A → B → A 会重新提交 A；撤回模块也会明确通知模型，防止省提示词导致旧人设、旧状态继续生效。
- 无状态 API、一次性研究规划、未确认可续接的外部引擎，以及新智能体接手，仍需必要的完整上下文。它们不能只收到一个无法解释的任务引用。
