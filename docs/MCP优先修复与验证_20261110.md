## 已完成

### 上下文重复

- 协作消息写入记忆时保存消息 ID，组装上下文时剔除已出现在最近消息中的记忆条目。
- 旧房间没有记忆 ID 时，按作者与原有 800 字符截断内容兼容去重，不要求迁移或删除历史数据。
- 好友长期事实、窗口之前的群记忆保留。主持人、成员和汇总使用相同的最近 40 条窗口，避免删掉重复记忆后主持人漏看第 21–40 条。
- 保留现有临时调用模式，没有直接改成持久会话，防止借降耗改变任务权限和会话隔离。

同一合成样本前后比较：

| 指标 | 修复前 | 修复后 |
|---|---:|---:|
| 40 条消息中出现重复标记的条数 | 40 | 0 |
| 单成员输入字符数 | 8,621 | 4,332 |
| 单成员输入 UTF-8 字节数 | 23,109 | 11,766 |
| 6 成员、主持及汇总冻结历史输入字符数 | 55,638 | 30,301 |

单成员字符数减少约 49.8%；这是本地合成输入测量，**不是实际计费 Token 或真实模型费用降幅**。修复后仍保留了合成好友记忆。

### 好友与房间隔离

- 开始执行前冻结好友、房间、数据目录、好友目录和配置快照。后台所有读取、成员调用及回写使用这份绑定。
- 切换好友时清空旧房间、聊天显示、输入框和旧排队消息；切换房间时清除旧排队输入。
- 完成与失败回调仅刷新原好友/房间仍在前台的界面，避免旧结果覆盖新界面。
- 队列项携带原好友和房间，出队时再次核对。去掉延迟启动计时器，避免队列衔接时短暂空闲，或旧回调延迟进入其他房间。
- 房间文件接口验证标识；列表采用实际文件名，读取时验证文件内房间 ID 一致，阻止路径穿越和伪造房间元数据。
- 对同一进程中的房间读改写事务加重入锁；实际验证 6 个线程写入 60 条回复，消息和记忆均完整保留。
- 修复成员指定模型写入错误字段：本轮覆盖 Codex、Antigravity 的专用模型字段，不调用模型进行验证。

### MCP

- 好友工具、手机工具、协作邮箱共用输入验证，坏 JSON、非对象请求、无效请求 ID 和非对象参数返回错误后继续处理。
- 初始化不再盲目回显任意版本：支持明确的旧版本集合，未知版本返回可用版本供客户端决定是否继续；未宣称支持完整最新规范。
- 好友工具清单排序稳定。
- 外部 MCP 工具发现跟随分页，加入重复游标检查、100 页/10,000 工具/时间边界，避免漏工具或无限循环。总耗时仍受单次 RPC 的超时粒度影响。
- 外部服务名不能覆盖内建好友工具、手机或协作邮箱；重命名后的名称冲突也会继续避让。
- 未改变现有 ToolRegistry、好友权限、工作任务工具裁剪、邮箱签名认证及审批边界。
