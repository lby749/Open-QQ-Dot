# Open QQ Dot 修复与测试记录（2026-11-10）

## 结论和交付范围

以桌面“最终发布”目录中的最新源码为基线。本次交付是工程验证版：已修复 EXE 启动、真实 QQ 任务分流、检索模型失效及界面直达等已重现问题；不能据此宣称所有功能、所有模型和所有操作系统均已验收。原始发布文件未覆盖。全程未调用 Claude，未删除或轮换 QQ 登录数据。

## 根因与修改

| 问题 | 根因及处理 |
|---|---|
| EXE 报 `_sqlite3` DLL 缺失 | 将 Conda/venv 解释器复制改名后，其依赖查找方式发生变化。A/B 实测原解释器可导入 SQLite，改名副本失败。删除复制解释器启动链，复用原 `.venv/Scripts/python.exe`。 |
| 冻结程序干扰外部 Python | 按 PyInstaller 官方说明重置 Windows DLL 搜索目录，移除子进程 PATH 中的冻结临时路径和父实例环境变量。启动器和安装器均使用同一处理。 |
| 校验通过但完整应用打不开 | 原校验漏查 SQLite、SSL 和完整界面模块。现在安装器验证这些模块，编译启动器的独立环境探针也验证完整应用导入。 |
| 左侧入口只变高亮不切页面 | Fluent 的 clicked 信号传布尔值，覆盖了 lambda 默认绑定的目标页面。回调明确接收点击参数；补做真实控件点击和原生桌面点击。 |
| 用量缓存切换好友后残留 | 控制台 30 秒缓存没有绑定好友目录。缓存键现包含好友目录，切换立即重新读取。 |
| 缓存命中率超过 100% | 历史 CLI 记录的输入量不含缓存，界面却按包含缓存计算。读取时统一口径；新记录保存口径标记以保持幂等，不改写历史数据库。非法统计不冒充有效用量。 |
| 经验/工具检索静默降级 | 内置加载器使用 transformers 已删除的私有接口，实际向量/重排未工作。改用公开的本地 from_pretrained 接口，关闭远程代码，实测真实模型确实调用。 |
| QQ 已收到任务但没有任务记录 | “帮我做一个任务：”没有进入任务委托识别。修正明确委托语句和文件任务分类，并保留假设、引用、闲聊等负例。 |
| 旧会话日志缺失阻断聊天 | 可选的会话交接检查依赖不存在的日志。仅跳过缺失日志这一可选检查；保留原有会话恢复和其他错误处理。 |
| 超时导致任务重复下发 | 原生调用返回不确定状态时明确中断，不自动再次提交、切 API 或切本地模型；清理本次调用拥有的子进程。 |
| 空环境安装/重复下载 | EXE 内置 uv 及授权文件；优先复用兼容 Python、已有 venv 和用户缓存；缺少时才下载。模型文件有匹配清单时按哈希复用，损坏文件单独重取。 |
| 非法好友参数退回全局统计 | 非法显式好友标识直接返回空结果；全局总览只由明确的无好友参数使用。 |

此前本轮已落地的协作上下文去重、好友/房间冻结绑定、迟到回调隔离、MCP 输入验证与工具分页等修改仍保留，详见同目录《MCP优先修复与验证_20261110.md》。该文是较早阶段记录，其中“未调用真实模型、未发 QQ、未重新打包”仅描述当时状态；本报告补充后续实测。

## 实际环境验证

- 真实 gpt-6-luna：低强度完成 QQ 聊天和文件任务；高强度单次请求成功。未借用 Claude。
- 真实 QQ：指定测试好友从 QQ 客户端发消息，收到模型回复；文件任务进入持久化任务管理器，状态为 COMPLETED，独立验收通过，实际读回文件内容一致；对端收到自然语言完成通知。
- 文件、图片、视频：实际发送链路及 QQ 对端的文件卡片、图片和视频缩略图已看到。未以缩略图冒充视频完整播放或手机端播放验收。
- 新 EXE 实际打开完整桌面界面，无 SQLite 启动错误。QQ 利用原登录记录恢复，无重新扫码；随后重载界面时保留在线运行时。
- 原生桌面实际点击“自主研究”可打开对应功能。回归覆盖 15 个直达入口、33 个工作区页面、48 次稳定切换及 100 次快速切换，未捕获异常或空页面。
- 独立安装目录：仅系统 PATH，不暴露本机 Python/Node；首次准备独立 CPython 3.12 和基础界面依赖用时 85.59 秒。再次修复复用已有环境，源码安装路径 12.17 秒，编译安装器路径先后为 6.12 秒和最终成品 4.88 秒。这里不是一台全新 Windows 虚拟机。
- 编译启动器在该独立目录的准备检查和完整应用模块导入返回 0，包含 sqlite3、ctypes、SSL 与 house_qt.window。
- 安装包内嵌 application.zip 已按 SHA256、ZIP CRC 和关键文件源码逐一比对；不携带真实好友、登录、工作区、数据库、模型权重和本机 QQ 运行时。uv 授权文件随 EXE 提供。

## 使用说明

新电脑运行同目录“一键安装启动”EXE；首次需要网络下载缺失的 Python/基础依赖。已有兼容环境和缓存会复用。可选向量运行环境、模型、浏览器及 QQ 运行时依其功能按需准备；未把未授权的第三方运行时和私人登录文件塞入包内。绿色包中的薄启动 EXE 必须与解压后的源码和资源放在一起，不能只复制它到别处。

原机升级安装器可识别邻近最终发布源目录。保留该目录的 friends、data、dotlink 登录状态和现有环境；选择新的空目录意味着新的独立实例。不要同时启动两套 QQ 运行时。

PyInstaller 外部子进程环境参考：https://pyinstaller.org/en/stable/common-issues-and-pitfalls.html#launching-external-programs-from-the-frozen-application
