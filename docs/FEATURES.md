# Open QQ Dot 功能与使用说明（BETA 测试版）

核查日期：2026-11-12。本文以当前桌面源码与已有验证记录为准，说明**实际可做什么、从哪里进入，以及还有什么限制**。BETA 不承诺所有功能、模型组合、账号和平台都已验证；过往截图、路线图与历史文档不能代替本版本的验收。

## 产品的主要用途

Open QQ Dot 在自己的电脑上运行，连接已合法配置的模型或智能体，为不同 QQ 会话提供人设回复，并在授权项目内执行可检查的任务。它还提供多智能体分工、可复用工作流、任务胶囊、有限研究、浏览器操作、资料学习和手机控制接口。

“本地”表示应用、配置、任务记录与本地权重由本机管理，**不表示所有推理都离线**。选择云 API、订阅 CLI、外部智能体或网页后端时，请求仍由对应服务处理，账号、额度和条款分别适用。

## QQ 连接：独立管理，可同时运行

### 官方 QQ 机器人：默认方式

在 **QQ 连接** 选择“官方 QQ 机器人”，填写自行申请的 AppID、AppSecret，按官方后台要求启用事件和测试成员/群。保存后显式连接。新发言人在本机授权之后才能使用模型；各机器人、群组和发言人映射独立会话。

支持多个机器人分别保存、连接与查看状态；其中一个失败不阻止其余连接或个人 QQ 启动。协作群可以绑定当前个人 QQ 为主智能体，每名工作成员绑定独立官方机器人。五个机器人已真实自动入群并确认各自群 OpenID，无须逐个扫码。已通过一次真实 Luna 主持人选择两名工作成员及思考强度、两只官方机器人各自回复、主账号汇总的完整链路，发送回执与真实群历史匹配。桌面可直接发起并查看群协作，发送未确认或成员失败会单独显示。自动建群仍未取得有效成功回执，普通好友邀请已按用户要求移出范围，官方媒体上传未完整接入；不能把这一次通过外推到任意任务、后端或所有机器人组合。见[本版发行说明](RELEASE_BETA3.md)。本项目并非腾讯官方产品，使用官方 API 也不构成品牌合作或平台背书。

### 个人 QQ 直连：保留的可选兼容方式

在同一连接页的方式下拉框选择“个人 QQ 账号直连”。原有快捷登录、窗口内二维码、密码登录、导入好友、聊天导出和诊断功能保留；只有外层页面滚动。

已有运行时会优先检测和复用；可选运行时不应无条件重复下载。NapCat 独立许可证和平台账号风险适用，参见根目录第三方声明。不要把直连运行时、登录目录或真实账号数据打入公开仓库。

已有验证覆盖自然中文往返、QQ 下达文件任务、真实产物与独立验收。历史媒体检查观察到文件/图片/视频卡片，不能据此声称所有客户端下载、音频播放和完整视频解码均已验收。

## 聊天、任务、流程和胶囊如何选择

1. **只想聊天**：在主页选择好友与会话，使用“直接对话”或自动判断；回复风格来自该好友的人设与偏好。
2. **明确要完成一件事**：在主页选择“执行任务”，或从全部任务选模板。给出项目、目标产物、范围和可检查的标准，确认它进入任务列表。
3. **一个长期目标**：使用自主规划或长期目标模板；先审查阶段，再按已有授权执行。预算不足、权限缺失、待验收或外部状态未知时会停下，不能保证无人工介入。
4. **下次还要做**：把通过验收的过程学习为工作流，编辑阶段与纠正，再设置执行次数/间隔。工作流不是无限后台循环。
5. **要携带或分享流程**：导出为任务胶囊。胶囊中的测试样例通常检查结构；真正运行时仍需执行工具并验收产物。不要把包含私人文件、链接或凭据的胶囊直接分享。

任务中心、专门的自主规划页面、工作流和胶囊都复用同一套 `TaskManager`；它们是创建与复用方式，不是四套独立后台。任务状态页是观察视图，不能把那里显示的“完成”替代具体验收内容。

任务结束时程序还会做有限的源码审查：常见缺陷、安全入口及静态 HTML 的部分 SEO 项目会进入详情，风险或检查不足可以转人工确认。它不等于完整漏洞扫描、线上渲染审计或搜索排名保证。

## 人设、模板与检索

快速配置由用户选择角色风格、关系及相关选项，再应用配套提示。公开资源包含 **1080 个组合提示，每组独立生成24条交替消息，转换为12个回复示例，共12,960个示例**。示例由五个手动选项精确路由，仅作为合成表达示范；不作为真实经历或任务经验，也不表示模型会自动判断所有人的人格。占用档共用文本与模型权重，向量缓存仍按实际模型和好友隔离。

配套示例已接入正式回复构造，实际 Luna 验证覆盖了有限风格/关系用例。模板内例句检索、风格遵循、选择哪套模板、任务成功率是不同指标，不能相互替代。

统一检索核心支持向量、关键词/BM25、融合、重排和去重，依据当前模型与作用域组装有限上下文。本轮修复了真实本地向量加载及重排失败后丢弃有效向量召回的回退问题。旧基准的标签或训练相似性不能当作独立测试；不应为了提高通过率把全部阈值放开。

权重只需保存一份，各好友可以选择不同生效配置。权重共享不等于共享聊天、人设、经验或向量结果缓存；集合仍需匹配对应模型签名和权限。

## 多智能体、MCP 与共用学习能力

### 自动反思与经验边界

任务失败时可用当前好友选择的后台模型生成有限反思，修正建议以未验证失败经验保存；重试使用这份反思，只有本次独立验收通过，才关联已验证的修正记录。同一任务的相同失败不重复调用，最多分析三类失败；调用结果未知时保留检查点，不自动重发。额度、时间或权限不足时保留原始错误，不能保证所有失败都能自动修复。

后台模型在桌面 **智能体与工具 → 模型来源 → 后台整理模型**、蓝色手机端 **全部 → 后台整理与反思** 配置。它与聊天模型独立，也可继承当前配置。反思只使用可关闭工具的纯文本通道；原生 DSH 或不支持该通道的外部工具会明确保留未完成状态，不扩大权限或静默切换模型。

**聊天历史不是经验库。** 普通聊天、收件箱回复、协作房间讨论不会自动作为任务经验或工作流。明确提炼的用户偏好、用户选择的候选做法、实际失败和通过客观验收的工作结果分别保存来源与可信状态。未经客观验收的完成声明只留在任务历史；旧会话不做整段迁移，也不自动删除。

Codex、DSH、Antigravity、OpenCode、ZCode、Cursor、Qwen、Kimi、ACP、自定义 API/MCP 等接入在同一模型与工具体系配置，但能力并不一致。已有真实验证包括 Luna、指定 Gemini、DSH 文件任务和 ZCode 文件任务；DSH 审查请求出现过超时，不能宣布该后端所有用途均稳定。未在本轮调用 Claude。

应用内协作群适合角色讨论；持久邮箱适合带身份、关联号和回执的跨智能体交接；胶囊适合可验收的顺序阶段。三者用途不同，不能把一次讨论完成当作代码已通过验收。

共用学习能力通过 `study_read/study_write` 供当前智能体使用：导入资料、检索引用、写笔记与计划、生成练习和保存反馈，不额外启动专用 DeepTutor 智能体。主观评语不等于客观评分，学习计划草案不自动成为执行中的长期任务。

MCP 按需提供运行摘要和获准工具，避免每轮复制全部配置、历史和文档；接入细节见 [AGENT_INTEGRATION.md](AGENT_INTEGRATION.md)。

## 手机、健康和通话

正式 Android 源码为 `android/`，沿用原蓝色小屋页面、原包名和手机控制功能；米色 `mobile/` 已停止作为发行入口。手机不内置 Python、QQ 运行时或全部本地模型。配对绑定好友范围，后台设置与协作房间共用电脑端配置及任务队列；Android 模拟器验证与实体手机、网络、后台保活及音频验收分别记录。

本轮蓝版覆盖后台模型/强度/额度原文、主智能体协作、按好友保存、同签名覆盖升级、无效配对保护和403/断线重连。模拟器实际操作及27项服务端检查、19项原生定向单测通过；不等于所有历史界面、硬件和实体手机均已验证。高级运行诊断仍有上游英文日志。

手机通话独立放在开发区：邀请是本地待领取队列，不是推送送达证明，也不是 QQ 原生拨号。通话链路及模拟器地址、音频处理等仍有缺口，见 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)。

健康试用已有 Android Health Connect 汇总读取与桌面授权/去重核心，未取得本轮真实健康设备数据。其他品牌目录不是已完成的厂商适配器。

## 其他保留能力的边界

- **图片/文件/视频附件**：有当前好友绑定、项目产物检查和审批；生成文件与成功发送是两个步骤，发送回执与对端实际播放也要分开。
- **语音识别、语音回复与声音克隆**：有本地模型/接口与声学处理代码，依赖相应模型、运行环境及素材授权；不能据此声称手机完整双工通话可用。
- **视频任务模板**：当前模板化脚本和有限渲染流水线可产生可解码文件，部分配置可能是纯色背景/提示音，不是已验收的通用视频制作 Agent。
- **电商比价/订单**：现有沙盒模拟路径不接真实电商平台，任务目录明确不提供正常创建，不可用于真实订单。
- **网页聊天后端**：兼容入口保留，依赖用户浏览器状态与外部网页变化，本轮没有完整真实网页账号验收，不承诺因此省额度或长期稳定。
- **多账号与多终端**：有账号目录、身份路由和隔离设计；多账号长期并发、官方多机器人群聊与全部终端组合没有完整实测。

## 已有验证与复现方式

### 软件更新推荐

设置与工具 → 版本与更新：启动后在后台检查公开发行信息，自动检查每天最多一次，同一新版只提示一次；支持手动立即检查和关闭自动检查。BETA 用户可收到后续测试版与正式版，正式版用户不被自动推荐测试版。更新说明按纯文本显示，下载入口固定指向本项目的 GitHub 发行页面，不自动执行远程安装文件。

发布打包时必须将 `release_source.json` 绑定到实际创建的本项目公开仓库。仓库尚未建立时页面明确显示“尚未配置更新来源”，不使用其他项目的版本冒充。版本筛选、缓存、离线与真实 Qt 组件已经验证；本项目在线发行页的完整闭环仍需首次发布后验证。

## 历史说明与现行入口的对应

| 旧说法/看似重复的入口 | 当前应如何理解 |
|---|---|
| “QQ 直连就是默认入口” | 当前默认官方机器人；个人直连是同页明确可选模式 |
| “任务中心 → 任务胶囊” | 当前任务胶囊有独立左侧入口；旧文档路径可能过期 |
| “长期任务与计划就是长期 Agent 总开关” | 该页主要配置主动聊天与关怀；长期工作用目标/工作流/胶囊 |
| “协作网络可以配置所有智能体” | 网络只观察实际运行；节点与分工在同一工作区的“协作流程”，接入与启用范围在原智能体设置页 |
| “聊天与审计和主页聊天是重复功能” | 主页负责交互/任务；审计负责查看历史、提示与检索证据 |
| “经验库和可学习工作流一样” | 经验库记录候选/结果知识；工作流是可执行、可编辑的阶段定义 |
| “手机工具、手机协作、手机通话都已接好” | 它们是不同路径，分别依赖对应客户端、权限和实机验证 |
| “测试全过就可宣称正式发行” | 本版本仍为 BETA；程序测试、账号验收、干净首装与平台验收必须分别看待 |
