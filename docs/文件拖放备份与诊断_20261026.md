# 文件拖放、双击、备份与诊断

## 拖放

把文件直接拖到主窗口即可：

| 文件 | 行为 |
|---|---|
| `*.oqtc` | 导入任务胶囊；可一次拖多个 |
| `*.oqdbackup` | 恢复数据备份（会先确认） |
| `*.json` / `*.jsonl` / `*.ndjson` / `*.md` / `*.txt` / `*.zip` | 打开迁移助手并预览 |
| 目录 | 迁移助手按目录读取 |

拖放不会上传文件；迁移预览阶段不会写入任何内容。

## 双击 / 打开方式

安装器勾选「关联 .oqtc / .oqdbackup 文件」后：

- 双击 `.oqtc` 直接导入任务胶囊；
- 双击 `.oqdbackup` 打开数据恢复确认；
- `.json`、`.jsonl`、`.zip`、`.md` 注册为 Open QQ Dot 的「打开方式」候选，可在资源管理器中右键选择，不抢占系统默认关联。

程序已运行时再次双击文件，会写入 `data/open_requests/` 队列，已有窗口轮询后处理，不会重复启动第二个实例。

## 数据备份

「设置与工具 → 迁移助手 → 数据备份与恢复」：

- 创建 `.oqdbackup`，包含好友、任务、回溯索引、迁移记录、胶囊和 DotLink 设置；
- 不包含 `dotlink/qq-data` 登录数据库、日志和缓存；
- SQLite 通过 sqlite3 backup API 复制，程序运行时也能得到一致副本；
- 恢复前把旧数据保留到 `_before_restore/<时间>/`，不会直接删除；
- 恢复后建议重启程序。

## 连接诊断

「QQ 直连」页 →「一键诊断」检查：

- 运行时 `index.js` / `node.exe`
- DotLink 管理令牌
- OneBot 配置
- 管理端口、管理接口鉴权
- QQ 登录状态
- OneBot `3001` 端口
- 快速登录记录

每一项失败都会给出下一步操作提示。

## 诊断包

「QQ 直连」页 →「导出诊断包」生成 zip：

- `report.json`：系统、Python、端口、关键文件状态；
- 最近日志尾部；
- 自动脱敏 `token`、`Authorization`、`password`、`secret`、`Cookie`、`Credential` 和 `Bearer` 值；
- 不包含聊天正文和登录数据库。

## 托盘与自动重连

托盘菜单新增：

- 连接 QQ
- 断开消息桥接
- 刷新连接状态

已登录时桥接进程退出，程序会在 30 秒内自动尝试恢复；用户主动点「断开」后不会自动重连。

## 全局撤销

- `Ctrl+Z` 撤销最近一次任务文件改动；
- `Ctrl+Shift+Z` 重做最近一次撤销；
- 输入框、聊天/文本编辑器获得焦点时不拦截，避免破坏正常文字编辑；
- 更细粒度的历史仍在「回溯中心」。
