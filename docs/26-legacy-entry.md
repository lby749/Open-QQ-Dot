# 旧版功能入口与 UI 回归

日期：2026-10-31

## 背景

vNext 桌面壳是只读聚合层，旧版 Qt 控制台里的发送聊天、完整表情管理、人格、日志等功能
没有全部迁移。此前新版 UI 没有明显入口，容易被误以为功能消失。

## 处理

1. 设置页新增“旧版控制台”区块：
   - 说明发送/完整表情/人格/日志仍在旧版
   - “打开旧版控制台”按钮
2. 安装包内置旧版程序：
   - `resources/legacy/Open QQ Dot.exe`
   - Tauri `open_legacy` 从资源目录启动
   - 首次启动旧版可能提示安装 Python/Fluent 依赖
3. 新增“表情包”页：
   - 读取好友收藏表情与含义卡
   - 网格预览、情绪/使用场景
   - 只读，不伪造发送
4. 布局修复：
   - 默认窗口改为 1440×900，最小 1100×720
   - 表单行允许换行，避免 1280 宽度下挤在一起

## 验证

- `cargo check` 通过
- Windows 安装版中点击“打开旧版控制台”实际启动了：
  `C:\Users\Administrator\AppData\Local\Open QQ Dot\resources\legacy\Open QQ Dot.exe`
- 旧版首次启动弹出依赖安装提示（未代替用户安装）
- 表情包页 API 与测试通过

## 注意

新版 UI 不会把旧版功能说成已迁移；旧版入口是真实启动旧程序，不是占位。
