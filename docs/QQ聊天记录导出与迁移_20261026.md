# QQ 聊天记录导出与平台迁移（2026-10-26）

## 导出 QQ 聊天记录

两种来源：

1. **本机直连导出**（推荐）：DotLink 已登录时读取 `get_friend_msg_history` / `get_group_msg_history`，分页去重，输出标准 JSON。
   ```powershell
   python -X utf8 tools/export_qq_history.py onebot --all --output exports\qq
   python -X utf8 tools/export_qq_history.py onebot --friend 123456 --output exports\friend.json
   python -X utf8 tools/export_qq_history.py onebot --group 987654 --output exports\group.json
   ```
   桌面端也可在「QQ 直连 → 聊天记录导出」完成。
2. **解析 QQ 自带导出**：`导出消息记录 → txt`（或已是 JSON/JSONL）。
   ```powershell
   python -X utf8 tools/export_qq_history.py parse "聊天记录.txt" --output exports\chat.json
   python -X utf8 tools/export_qq_history.py parse "聊天记录.txt" --output exports\chat.jsonl --form jsonl
   ```
   `.mht/.html` 暂不支持，会明确提示改用 txt 或直连导出。

输出格式 `openqqdot.transcript/1`：

```json
{
  "schema": "openqqdot.transcript/1",
  "source": {"platform": "qq", "kind": "friend", "id": "123456", "title": "小明", "self_id": "10001"},
  "participants": [{"id": "123456", "name": "小明"}],
  "messages": [{"id": "…", "timestamp": 1700000000, "sender_id": "123456", "role": "user",
                "type": "text", "text": "你好", "media": []}],
  "stats": {"message_count": 1},
  "integrity": {"message_digest": "…"}
}
```

可用 `--form jsonl|sharegpt|markdown` 进一步转换；`sharegpt` 会合并连续同角色消息。

## 迁移其他平台的对话与项目

```powershell
python -X utf8 tools/migrate_chats.py "chatgpt-export.zip" --friend 12345 --inspect
python -X utf8 tools/migrate_chats.py "chatgpt-export.zip" --friend 12345 --project "旧对话"
```

支持自动识别：

| 来源 | 识别方式 |
|---|---|
| ChatGPT | `conversations.json`（含 `mapping`）或官方 `.zip` |
| Claude | `conversations.json`（含 `chat_messages`） |
| DeepSeek / Open WebUI / 通用 | `messages` / `chats` / `data` 包装的 JSON |
| SillyTavern | `.jsonl`，每行 `{name,is_user,mes,send_date}` |
| Markdown | `.md` 作为项目资料导入 |

迁移会：

- 在 `data/migrations/<导入编号>/` 保留标准 JSON 与 `manifest.json`（来源、哈希、会话、项目、警告）；
- 通过 `session_manager` 创建真实项目工作区与会话，可在桌面继续使用；
- 在 `data/migrations/index.json` 记录，重复导入同一来源默认不重复写入（`--force` 可强制）；
- 不修改源文件，不复制账号/令牌，不联网。

撤销：桌面「设置与工具 → 迁移助手 → 撤销最近一次」，或 `revert_center`。导入包移到 `_trash/`，会话与工作区移除，不硬删除原始导出。

## 边界

- ChatGPT 只取 `current_node` 主线，分支对话不会全部展开。
- 图片/文件只保留 URL 或占位文字，不保证下载成功。
- 单文件上限 256MB、最多 5000 个会话；更大的导出请先拆分。
- 迁移后的会话用于继续阅读和作为项目资料，不会自动当作人设训练数据；需要训练时走现有数据集导入流程。
