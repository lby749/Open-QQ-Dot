## 本轮修复的根因

1. 好友切换时，DSH 的可编辑模型输入框清空后用选择列表的方法恢复，导致手动配置模型变空。改用可编辑文本恢复；网页模型也沿用这个恢复方法。
2. 干净 Windows 没有系统 VC++ 运行库，QQ 原生组件加载失败。连接子进程现在通过自己的环境复用已安装 Qt 依赖中的运行库；不改系统 PATH、不复制宿主 DLL、不额外下载安装。修复后连接运行时实际启动成功。
3. Codex 安装原先先要求 npm/Node.js。Windows 分支改用固定版本且校验摘要的官方安装脚本，并识别官方独立安装位置；下载或安装失败给中文提示。沙箱联网受阻，**此工具的实际自动下载安装尚未通过**。
4. 模型来源的安装按钮缺少开始反馈，也允许同一来源重复排队。增加即时反馈与同来源任务保护，失败后可以重试。
5. 重新开启节点或上级分支时，可能让两个节点占用同一机器人。现在在保存节点及根入口变化时统一验证所有有效分支，拒绝冲突且保留原文件。
6. 顶部切换器用容器字体计算按钮宽度，实际按钮字体更大，选中后更粗。改用按钮实际字体并为选中态留足宽度。
7. 安装日志展开后窗口可能越出屏幕，进度状态透出英文下载诊断；调整窗口定位并提供中文进度，原始诊断仍保留在日志。
8. 重复打包时源码包可能混入 `dist/` 中的已编译 APK。共同过滤和独立归档检查现在排除整个发行输出目录与 APK，源码、安装器、手机安装包分别提供。没有将本地候选包上传。
