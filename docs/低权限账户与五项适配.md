# 低权限账户与五项适配

## 1. 什么算低权限

`oqdot-agent` 应是**标准本地用户**，不是管理员：

```powershell
# 管理员 PowerShell 执行
New-LocalUser -Name "oqdot-agent" -NoPassword -AccountNeverExpires
Add-LocalGroupMember -Group "Users" -Member "oqdot-agent"
# 确认不在管理员组
Get-LocalGroupMember -Group "Administrators"
```

要求：

- 不在 `Administrators`
- 没有 `SeDebugPrivilege`、`SeBackupPrivilege`、`SeRestorePrivilege`、`SeTakeOwnershipPrivilege`
- 不能登录远程桌面
- 不能读取主程序数据目录
- 只能读写自己的 workspace

ACL 示例：

```powershell
$app = "D:\OpenQQDot"
$work = "D:\OpenQQDot\workspaces\agent"

# 主程序数据：只允许所有者/系统/管理员
icacls $app /inheritance:r
icacls $app /grant:r "$env:USERNAME:(OI)(CI)F" "SYSTEM:(OI)(CI)F" "Administrators:(OI)(CI)F"

# Agent 工作区：只给 Agent 改
icacls $work /grant:r "oqdot-agent:(OI)(CI)M"
```

运行 Agent 时用该账户：

```powershell
$cred = Get-Credential oqdot-agent
Start-Process -Credential $cred -FilePath "codex.exe" -ArgumentList "..."
```

> 当前程序没有自动切换账户；这是部署层隔离。若需要我把它做成一键“以低权限账户运行 CLI”，需要再加启动器。

## 2. 多智能体协同适配

已补：

- `AGENT_SPECS` 加入 `webchat_deepseek`、`webchat_chatgpt`、`webchat_gemini`
- `DEFAULT_MODEL_SPECS` 加入对应路由标签
- `main.codex_text` 增加 webchat 分支

仍然限制：

- 网页端在多智能体里启用网页 Agent 后可使用工作区工具；未启用时只做分析
- 要工具执行，仍应使用 Codex / Claude / Antigravity / 本机执行 Agent
- 网页 Agent 的 `desk_*` 工具循环是独立路径，不会自动出现在多智能体编排里

## 3. 向量模型不再下载即启用

已删除：

- 下载完成后自动写 `local_models_enabled=True`
- 下载完成 UI 自动勾选本地模型

现在下载只代表“已安装”，要在模型页显式开启才会用于检索、人格等。

已有旧配置 `local_models_enabled=true` 不会被强制改回；需要手动关闭。

## 4. 网页 Agent 的 PowerShell 和文件能力

已确认/保留：

- `desk_read_file`
- `desk_write_file`
- `desk_list_files`
- `desk_run_command`（Windows PowerShell）
- 受好友工作区、只读模式、命令权限控制

网页 Agent 的开关在「网页 Agent 执行」，需要同时启用电脑工具权限。

## 5. 命令行工具选择

新增「命令解释器」：

- PowerShell 7 (pwsh)
- Windows PowerShell 5
- CMD

保存到 `computer_tools.shell`，`desk_run_command` 按选择执行。  
Codex / Claude / Antigravity 等 CLI 仍由模型来源卡片选择，互不影响。
