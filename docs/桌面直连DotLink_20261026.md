# DotLink：桌面直连 QQ（不再打开网页扫码，2026-10-26）

DotLink 是 Open QQ Dot 自己的 QQ 连接工具。它把启动、登录与 OneBot 连接全部放进桌面端，不再让人打开浏览器里的 WebUI 页面扫码。底层使用随程序提供的本机 QQ 协议运行时；DotLink 的生命周期、登录编排、二维码渲染、聊天导出与界面都是本项目重写的代码。

## 启动流程

1. `launcher.py` 在窗口显示后调用 `dotlink.ensure_started(home)`。
2. `dotlink.prepare()` 在 `dotlink/` 下建立 DotLink 自己的状态，不读取旧客户端的令牌或登录态：
   - `dotlink/local.json`：DotLink 自己生成的 OneBot 与管理令牌、端口、jwt secret；
   - `dotlink/state/config`：运行时工作目录（配置、日志、二维码缓存）；
   - `dotlink/qq-data`：**独立的 QQ 登录数据目录**。首次使用必须在这里单独登录，不会复用其他客户端的登录令牌；
   - 内置运行时以 `qq-runtime` 暴露（安装器创建目录联接），代码不依赖其目录名。
3. `dotlink.start()` 启动内置运行时。路径含中文或空格时自动用 `subst` 映射短盘符，避免 QQ 原生加载器的路径问题。
4. 登录优先走该 `dotlink/qq-data` 内的快速登录记录；没有记录就显示二维码。

## 登录：快速登录与二维码都在桌面里

管理接口只监听本机，认证方式与官方前端一致：

- `POST /api/auth/login`，提交由本地管理令牌派生的哈希，返回 `Credential`；
- 后续请求带 `Authorization: Bearer <Credential>`。

拿到凭据后：

- **快速登录**：`GET/POST /api/QQLogin/GetQuickLoginListNew` 读取本机保存的账号；
  `POST /api/QQLogin/SetQuickLogin {"uin": ...}` 直接发起免扫码登录。
- **扫码登录**：`POST /api/QQLogin/GetQQLoginQrcode` 返回 QQ 登录 URL；DotLink 用 `qrcode` 在本地渲染成 PNG，显示在
  「QQ 与会话 → QQ 直连」页面，不再打开 `http://127.0.0.1:6099/webui`。
- **状态轮询**：`POST /api/QQLogin/CheckLoginStatus`，页面每 2.5 秒刷新；`isLogin` 后停止。
- 登录成功后 OneBot 适配器自动启动，端口 `3001` 就绪，桥接可连接。

相关接口来自本机运行时的静态分析；没有调用云端服务，也没有新增远程端口。

## 页面与按钮

- 侧栏「QQ 与会话 → QQ 直连」：状态、快速登录账号、扫码二维码、启动/修复、停止、连接桥接、运行日志。
- 顶部「连接 QQ」：若 `3001` 已监听，直接启动桥接；否则打开本页并开始登录。
- 「从 QQ 导入好友」：登录后读取当前账号好友列表，勾选后逐个添加为 Open QQ Dot 好友；已有好友不会重复添加。
- 「聊天记录导出」：导出全部好友/群聊或当前好友为迁移 JSON，见 `docs/QQ聊天记录导出与迁移_20261026.md`。

## 配置与安全

- 管理接口与 OneBot 只监听 `127.0.0.1`；客户端拒绝非本机 WebSocket 地址。
- 令牌只写入 `dotlink/local.json` 与 `dotlink/state/config/webui.json`，均被 `.gitignore` 排除；不读取任何旧客户端的令牌文件。
- 不复制 QQ 密码，不缓存管理凭据（每次启动重新换取），不把令牌写入胶囊、迁移包或聊天导出。
- QQ 数据目录固定为 `dotlink/qq-data`；运行时若缺少数据目录注入会给出警告，避免误用真实 QQ 数据目录。

## 仍然存在的边界

- 首次在本机登录、或快速登录态已失效时，必须在桌面窗口扫码一次；这是 QQ 的登录要求，不是网页依赖，也不复用别的客户端登录。
- QQ 风控可能拒绝登录（例如提示账号安全风险），此时需要先在手机 QQ 处理，程序不会绕过。
- 管理端口被占用时会自动顺延；程序优先读取运行日志中的实际地址，而不是硬编码 6099。
- 多账号并发登录、QQ 版本升级后配置结构变化、以及长期稳定性仍需实机验证。
