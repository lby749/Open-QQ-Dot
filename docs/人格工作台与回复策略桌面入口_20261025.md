# 人格工作台与回复策略的桌面入口（2026-10-25）

> 本文中的账号均为脱敏占位示例，不可用于实际发送。

此前已实现、但在 Qt 桌面版没有入口的功能，现都在「设置与工具 → 人设与指令 → 人设与回复风格」页底部，只作用于当前好友。

## 回复策略（情绪 · 时机 · 记忆）

对应 friend.json 的 `emotion_policy`、`timing_policy`、`memory_policy`。填写即开启，清空即关闭（键被删除）。

- **情绪策略**：开启情绪判断。每次回复先判断对方情绪，并按人设维持自己的心情，记录在「情绪」页。未开启时，「情绪」页会显示提示。
- **时机策略**：回复时参考本机记录的收发时间（间隔多久、几点）。
- **记忆策略**：规定长期记忆怎么用、什么时候提；长期记忆本身始终会被检索。

## 人格工作台与检索增强

五个按钮在独立窗口打开原有的 Tk 工作台（Qt 不能内嵌 Tk，所以由 `persona_workbench_host.py` 在子进程中打开）。同一好友同一工作台只开一个窗口：

| 按钮 | 模块 | 用途 |
| --- | --- | --- |
| 人格提炼任务 | `persona_gui.py` | 从聊天记录生成人格包 |
| 人格版本与示例 | `persona_friend_gui.py` | 确认版本、管理示例 |
| 兴趣、知识与贴纸 | `persona_knowledge_gui.py` | 编辑兴趣、知识条目，查看贴纸 |
| 人格 A/B 对比反馈 | `persona_feedback_gui.py` | 比较两个版本的回复效果 |
| 检索诊断（只读） | `retrieval_debug_gui.py` | 查看回复时实际取到的上下文 |

开关对应 `feature_flags`。勾选只是预览，点「应用到当前好友正式回复」才写入；未知的其他开关原样保留。

- **人格检索**（`persona_enabled`）：回复时取用已确认的人格、示例与风格。
- **混合检索**（`hybrid_enabled`）：取用结构化资料、兴趣与知识条目。
- **贴纸元数据**（`sticker_metadata_enabled`）：检索路径尚未接入，开关只显示、不能更改。

数据或模型缺失时，回复自动降级为原有上下文，不会中断。

旧版 Tk 面板（`gui.pyw`）曾把前四个工作台隐藏、改用「人格模板」，只保留「检索诊断」页。本次按需求重新开放，人格模板功能不受影响。

## 修复

还没跑过人格提炼任务的好友没有 `persona.sqlite3`。此前除「人格提炼任务」外，其他工作台打开即报 `persona sidecar is absent`。现在打开任一工作台时，若文件不存在，先创建空的人格库（与「人格提炼任务」打开时的做法相同）。
