# 宣传视频与使用视频

视频由本地截图和 Pillow + ffmpeg 生成，不依赖外部剪辑软件。

## 产物

- `exports/videos/OpenQQDot-Promo.mp4`
  - 1920×1080，约 84 秒
  - 产品定位、桌面直连、手机端、功能矩阵、部署流程
- `exports/videos/OpenQQDot-Tutorial.mp4`
  - 1920×1080，约 2 分 10 秒

两条视频都带生成的低音量环境音乐，无第三方版权音乐。


## 手机端测试

桌面端运行时，用 MuMu 命令行和 adb：

```powershell
# 启动模拟器（若未启动）
& "D:\Program Files\Netease\MuMu\nx_main\MuMuManager.exe" control -v 0 launch

# 安装并打开手机应用/网页
python -X utf8 tools/mobile_smoke.py --qq <好友QQ>

# 仅测试网页版
python -X utf8 tools/mobile_smoke.py --qq <好友QQ> --browser
```

脚本会执行 `adb reverse`、打开 `friendhouse://pair...` 深链、依次点开状态/控制台/聊天/记忆/全部，并把截图保存到 `exports/mobile-smoke/`。
