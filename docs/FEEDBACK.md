# 问题反馈与改进建议

当前项目仍在 BETA 测试阶段，尚不完善。欢迎提出改进建议，非常感谢。

应用内入口：**设置与工具 → 版本与更新 → 反馈问题与改进建议**。也可以直接打开[问题反馈与建议](https://github.com/lby749/Open-QQ-Dot/issues/new/choose)，选择问题反馈或改进建议。

反馈问题时，请写明应用版本、操作系统、重现步骤、预期行为和实际行为；如有必要，可附已脱敏的截图或错误片段。不要提交密钥、访问令牌、登录二维码、真实账号和私聊原文。程序不会自动收集或上传诊断资料。

感谢您的支持，如果有帮助的话，请点一个 STAR，谢谢。
