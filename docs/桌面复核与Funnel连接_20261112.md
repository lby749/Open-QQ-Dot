# 桌面复核与 Funnel 连接（BETA）

日期：2026-11-12。基线为「最终发布」源码。本记录区分代码检查、真实组件、真实模型与 QQ、设备及外网验证，不把它们合并成“全功能已经通过”。本轮没有使用 Claude；私人数据不进入发行包。公开发布状态以对应 BETA 发行页与校验清单为准。

## 本轮修复

- **远程连接入口**：在「连接与会话 → 移动设备与网页访问」加入「一键打开并配置 Funnel」及关闭按钮。复用已安装的 Tailscale；缺少时下载并校验官方固定版本 MSI，有效缓存不重复下载。安装和连接在后台进行。
- **连接状态可信度**：检查实际转发目标，并以不携带好友令牌的 HTTPS 请求验证应用入口。规则存在但公网不通时不报成功、不切换远程二维码。没有远程地址时，不再显示手机无法使用的本机回环二维码。本机浏览器链接仍保留。
- **配置保护**：避让已占用的 Funnel 端口，不执行全局 reset。关闭时先拒绝应用的 Funnel 请求，再移除匹配端口的根路径转发。默认仍关闭 Funnel；每位好友的 API 令牌和访问范围继续独立。
- **语音输入**：默认 Paraformer 小型 Q8/INT8 模型，文件合计 81,904,027 字节，安装包不含权重，首次自动准备、后续复用。保留其他语音模型作为手动选择，识别设置移至「智能体与工具 → 本地模型与语音」首位并默认展开，提供下载/修复入口。控制台输入工具栏压成一行；现已移除录音对话框，点一下开始、变为停止图标，再点一下结束并转写，结果只填入草稿，不自动发送。
- **下载证书**：模型下载复用系统及公开 CA 信任链，未关闭证书或主机名验证。修复干净 Windows Python 环境缺少公开 CA 时下载失败的问题。
- **输入误提交**：网页及桌面输入框在中文输入法组词期间不把回车当作发送；正常回车发送保留。
- **切换好友的迟到响应**：浏览器中复现并修复旧好友请求返回后覆盖新界面的情况，增加好友、页面和请求版本检查。
- **常驻指令同步**：同一好友在快速配置或其他入口更新指令后，未编辑的页面会刷新；未保存草稿保留，保存冲突时拒绝覆盖，并提供重新载入。
- **桥接启动误报**：独立 Python 启动器父进程退出时，重新核对本目录真正运行的桥接子进程，修复子进程已经正常运行却显示启动失败的问题。
- **测试隔离**：群聊和桌面 Qt 测试使用临时数据根，并禁止连接真实 QQ；修正新需求对应的旧导航、权限、模型下载和分析方式预期。

## 真实组件与账号验证

- 在此前从零安装的 Windows Sandbox 副本继续验证。它是本机沙箱，**不是远程云主机**。
- Q8 模型在该副本实际下载，固定版本和文件 SHA-256 均匹配，总文件大小低于 100 MB。第二次准备复用文件，修改时间未变。公开中文音频样例实际识别成功：冷启动约 3.015 秒，同一样例预热后约 0.141 秒。该单样例不能代表完整准确率或所有设备性能；没有录制用户麦克风。
- Tailscale 从未安装状态实际下载、校验并安装成功，停在“需要登录 Tailscale”，没有伪造已经连通。宿主已有客户端与匹配的转发被复用，既有转发配置没有变化；实际公网 HTTPS 探测仍失败，界面会明确显示未连通。
- 快速配置实际重新打开，保存的人设、关系、频率、用途、占用档位及权限得到恢复。实际点击模型提取，列出当前 Codex CLI 的 8 个模型及当前模型支持的思考档位。目录提取不代表逐个模型都有额度或已验收调用。
- 沿用此前同轮已通过的真实模型与 QQ 记录：私聊、群聊、邮箱及自动选择路线有真实模型返回与收发回读；工作台和私聊入口的协作流程有运行记录，另一好友查询为空。手机 API 消息实际进入 QQ，QQ 端消息回填到同一会话，稳定消息标识避免重复，跨好友访问返回拒绝。权限拒绝消息实际发送，未调用模型。拒绝输入来自受控桌面调度，不冒充新发生的人类 QQ 入站事件。
- 刷新 GUI 后，还实际重启消息桥接以加载新源码：桥接进程已更换且持续运行，原 QQ 登录进程及创建时间不变，QQ 在线，好友配置未改动，没有中断执行中的任务。没有要求重新登录 QQ。
- 前一阶段实际打开过控制台语音对话框并取消；该交互现已被下文的直接点按方式替代。实际进入首位的语音设置页并点击「一键下载/修复」，已下载模型很快就绪。不是只检查控件存在。

## BETA.4 语音点按与安装复核

按用户反馈，移除原来的“打开录音窗口后再开始”的交互。控制台同一按钮首次点击直接开始录音，并变为停止图标；第二次点击停止，在后台转写。转写中暂时禁用按钮，结束后恢复麦克风图标，文字只填入草稿。离开页面、切换好友或会话会取消当前录音；旧任务的迟到结果不进入新会话。麦克风缺失、权限拒绝、设备启动失败和无有效内容均明确提示，不自动发送消息。单次最长 60 秒。

- 语音及导航相关 **25 项检查通过**，覆盖两次点按、图标变化、无录音对话框、权限授予后自动开始、设备不可用、重复停止、切换页面和迟到回调。检查中使用麦克风替身，不是物理录音验收。
- 在实际 Windows Sandbox 内，让新录音控制器读取同一个公开中文 WAV，经真实 PCM 缓冲、临时 WAV、后台任务和已下载 Q8 模型返回中文文字；状态依次为录音、转写、空闲，实测约 **1.25 秒**。首次脚本因漏初始化界面线程分发器超时，修正验证脚本后通过；没有把超时记作成功。音频设备输入被公开样例替代，没有使用用户麦克风，也没有发送 QQ 消息。
