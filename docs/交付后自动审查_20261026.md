# 代码与项目交付后的自动审查

代码任务，以及交付源码的文件任务，现在会在原有验收流程中自动进行自审和独立静态检查。适用于统一编排、原生外部智能体和 Codex App Server 执行入口；没有增加额外模型请求，也没有改变原有工具权限。

## 执行流程

1. 执行智能体在交付前重新阅读修改及相关调用，检查逻辑缺陷、异常边界、权限、输入与敏感数据；在已有授权内修复并做相关测试。
2. 程序继续运行原有的文件、Python 语法及已配置测试验收。
3. 程序独立读取本次修改和指定目标源码，检查常见风险；发现风险候选或检查不完整时，原本可通过的任务改为“等待确认”，不会仅因测试通过便自动完成。
4. 问题清单随任务的 `verification_info.code_review` 保存到任务数据库。桌面任务详情原有的“独立验收”区域显示中文说明和文件行号；任务 API 也返回相同数据。修复后重新执行验收会重新检查实际文件，不复用旧的安全结论。

普通闲聊、研究和智能体邮箱通信不增加此自审提示。学习工作流中的代码阶段照常经过相同验收。

## 检查内容与边界

- Python：语法错误、可变默认参数、动态执行与反序列化入口、未指定安全 Loader 的 YAML、关闭证书校验和 shell 命令执行等风险候选。
- JavaScript、TypeScript 与网页源码：部分动态执行和 HTML 注入入口。
- 源码中的部分硬编码凭据模式：只报告文件位置，不回显凭据值。
- 静态完整 HTML 页面：标题、描述与禁止索引设置。`noindex` 可能保护内部页面，只提示核对，不自动删除。
- JSX、TSX、Vue、Svelte：明确需要补实际渲染检查，不能把组件源码当作已通过线上 SEO 检测。
- 其他常见源码语言：明确提示缺少对应语言分析器，不声称已完成语法与安全分析。

这是有限的静态检查和智能体自审要求，**不是全面安全审计、漏洞不存在的证明或搜索排名保证**。风险入口也可能有合法用途，程序不会据此擅自重写逻辑。依赖漏洞、认证业务逻辑、线上 HTTP 响应、页面渲染与搜索收录等仍需专项验证。

读取限定在任务项目内，每轮最多 100 个源码文件、单文件 256 KB、总计 2 MB；问题最多保留 200 项。路径超界、无法读取、超限、已删除或分析器缺失都会说明。扫描不执行待审源码、不联网、不上传源码、不修改文件。

## 本轮实测

- 真实 Codex 执行两项隔离任务，各一次模型调用，自审要求确实进入请求。
- 数字解析任务：移除原有 `eval`，语法和静态检查通过；程序另行验证合法正负整数及表达式、空串、动态导入等非法输入。
- 公开教程首页：生成中文标题、描述和语义化导航，静态审查通过。没有声称已完成浏览器或线上收录检测。
- 两项任务均取得独立验收回执；未向 QQ 发送测试消息，未修改真实好友配置。
- 自动回归覆盖测试通过仍有安全风险、修复后通过、凭据不回显、缺失元数据、私有页面禁止索引、读取边界、源码超限、任务重启后审查记录保留等情况。

回归结果：首次单进程全量运行有 1826 项通过、451 项子测试通过、2 项平台跳过、7 项失败。失败分别来自自审提示改变后的旧断言（1 项）、固定端口测试服务未关闭而连错服务（5 项）、自审提示放在任务末尾使追加说明无法复用会话（1 项）。已更新断言、修复测试服务端口与清理，并将稳定自审要求放到任务开头，保持原任务追加反馈的前缀关系；修复后相关 **62 项测试及 15 项子测试全部通过**，包含全部原失败项和 17 项新增审查测试。另一次界面与任务相关回归 70 项通过（其中新增审查测试的后续补充另有覆盖）。没有把初次全量失败记录改成“全量零失败”。

初次全量还暴露了嵌入模型测试替身缺少 `torch` 属性导致后台空闲卸载线程报错的警告；本轮未改动无关的向量模型生产逻辑。该警告不应当作真实 GPU 加载或卸载已验证的证据。

真实调用结果：工作目录旁 `audit-20261024/live-post-delivery-review-20261026.json`。脚本最初在最终控制台输出遇到 Windows 编码问题，但已落盘的两个任务及验收结果均通过；已修复输出编码，未因此重复调用模型。

测试记录：同目录 `post-delivery-review-regression-20261026.xml` 保存初次全量结果，`post-review-fixes-regression-20261026.xml` 保存修复后的相关回归。运行中的旧进程需重启后才加载新逻辑；此前任务不会被自动重跑。更新开发包为 `Open-QQ-Dot-Development-20261026-Review.zip`，仍不是已完成全部开源验收的正式发行版。

安全入口参考 [Bandit 的 YAML 检查说明](https://bandit.readthedocs.io/en/latest/plugins/b506_yaml_load.html)；静态元数据、渲染与索引的区别参考 [Google 的 JavaScript SEO 文档](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics)。本次没有安装或冒称执行 Bandit、浏览器 SEO 工具或远程漏洞扫描器。
