# 任务胶囊、可学习工作流与回溯中心（2026-10-26）

## 任务胶囊是什么

一个 `.oqtc` 文件（zip），把一套复杂的 AI 工作流打包成可复用工具：

```
manifest.json          身份、版本、模型/权限要求、文件 SHA-256、整体摘要
workflow.json          可学习工作流定义（阶段、智能体、预算、验收参数）
skills/<name>/SKILL.md 该流程依赖的技能说明（纯文本）
samples/samples.json   测试样例：输入与期望字段/文字/完成状态
demo/demo.json         自动化示范：浏览器示教步骤或真实运行轨迹
README.md              导入说明
```

导出时从现有 `WorkflowStore` 读取已验收/已编辑的版本，再用 `clean_definition` 重新校验；不会加入额外权限。

```powershell
python -X utf8 tools/capsule_cli.py export --friend 12345 --workflow workflow_xxx --output my.oqtc `
    --title "每周竞品报告" --description "抓取、核对、生成周报" --skill .\skills\research\SKILL.md
python -X utf8 tools/capsule_cli.py inspect my.oqtc
python -X utf8 tools/capsule_cli.py import my.oqtc --friend 12345
python -X utf8 tools/capsule_cli.py run --friend 12345 cap_xxxxxxxx
python -X utf8 tools/capsule_cli.py test cap_xxxxxxxx
```

桌面：「任务中心 → 任务胶囊」可导入、查看、结构测试、运行、卸载，也能从可学习工作流直接导出。

## 作为工具调用

- 模型通过 MCP 看到 `capsule_list`、`capsule_inspect`、`capsule_test`、`capsule_run`。
- `capsule_run` 只创建现有的持久化目标（`WorkflowStore.run`），仍经过：
  - 当前好友已启用的智能体检查；
  - 项目文件/命令权限检查；
  - 每阶段调用与词元预算；
  - `TaskVerifier` 客观验收与人工确认；
  - 审批（QQ 消息、命令等敏感操作）。
- 胶囊不能携带可执行代码；成员白名单只允许 JSON/Markdown/文本/图片；任何路径穿越、超限、哈希不符、疑似密钥都会被拒绝。

## 从运行中学习

- 已通过验收的长期目标 → `tools/capsule_cli.py learn --friend 12345 --goal goal_xxx`：
  - 调用现有 `WorkflowStore.learn` 生成工作流；
  - 样例来自各阶段声明的验收字段；
  - 示范记录保存阶段、智能体与状态；
  - 生成并安装胶囊，默认不自动重复执行。
- 也可先在「可学习工作流」里纠正/编辑版本，再导出胶囊；胶囊是版本化快照，不会随源工作流悄悄变化。

## 回溯中心

「系统洞察 → 回溯中心」把各类撤销集中到一条时间线：

| 类型 | 撤销行为 | 是否可重做 |
|---|---|---|
| 任务文件 | 新建文件移入 `undone/`，修改/删除还原；内容被再次修改则拒绝 | 是（`task_undo.redo`） |
| 长期目标 | 终止未完成阶段，按阶段从后往前撤销文件 | 否（可重新执行） |
| 平台迁移 | 移除项目/会话，导入包移到 `_trash/` | 否（可重新导入） |
| 任务胶囊 | 移到 `data/capsules/_trash/`，保留已创建工作流 | 否（可重新导入） |
| 长期记忆 | 恢复上一记忆版本（恢复前自动快照） | 否 |

其他改进：

- `revert_center` 用 SQLite 索引 `operation_id = owner:kind:target`，重复登记不会产生重复行；
- 撤销前可预览具体文件与会话；
- 任务撤销后可「重做」，撤销/重做历史都写回 `task_undo` 日志；
- `prune` 只删除 60 天前已撤销的索引记录，文件和回收目录不动；
- 撤销不会硬删除用户内容；已发出的 QQ 消息、网页提交等外部副作用仍不可撤销，界面会明确说明。

## 数据位置

```
data/capsules/index.json          已安装胶囊索引
data/capsules/<id>/<version>/     胶囊文件
data/capsules/_trash/             卸载后的胶囊
data/migrations/<import_id>/      迁移包与 manifest
data/migrations/_trash/           撤销后的迁移包
data/task_undo/<task>/            任务文件撤销日志
data/revert/index.sqlite3         回溯时间线
```

## 验证

- `tests/test_task_capsule.py`：导出/校验/防篡改/路径穿越/密钥拒绝/权限要求/学习。
- `tests/test_revert_center.py`：任务撤销重做、迁移撤销、胶囊卸载、重复撤销拒绝。
- `tests/test_platform_migration.py`、`tests/test_qq_history_export.py`：迁移、导出、分页、媒体、幂等。
- `tests/test_dotlink.py`：配置、令牌、QR 渲染、WebUI 鉴权、状态。
- `tests/test_windows_installer.py`：预检、标记、修复安装、校验拒绝。

这些测试不代替真实账号、真实模型与真实 QQ 客户端的端到端验收。
