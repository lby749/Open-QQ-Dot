# Open QQ Dot 1.0.0-beta.3

本版仍为 BETA 测试版。用户已明确暂缓自动新建 QQ 群，它不列入本次发布门槛；不表示该能力已经修好。请使用已有 QQ 群，保留多机器人接入、协作分工及汇报功能。

## 本次修正

- 用量统计只解析当前好友拥有的完整 Codex 会话。其他近期会话仅限读取末尾 128 KiB 的账号额度事件，不再为刷新界面解析其他好友的完整对话。
- 切换或删除好友后，模型设置的延迟刷新不再读取已不存在的配置；关闭窗口后也不再应用迟到的好友状态。
- 协作栏目合并后清除导航清单中的重复别名；保留协作流程配置与协作运行观察的分工。
- 主题刷新先获取稳定的控件快照。修复了控件销毁时同步移除登记项、导致界面库遍历集合抛错的问题；不吞掉异常或跳过整组界面检查。
- 经验状态审计改用独立随机编号。修复了虚拟机时钟粒度较粗时，连续状态写入撞号而丢失经验归档的问题；已有数据库不迁移、不清空。
- 本地运行环境安装以实际导入为准。深度检查每次实际导入，状态显示优先采用该结果；旧失败不会阻止补装后重检，成功后清除旧的浅层状态缓存，避免重复安装或误报。
- Windows 向量环境通过运行依赖包补齐 C++ DLL，只部署到当前虚拟环境的 Torch 目录，保留已有文件和许可证，不安装系统运行库。已可用的环境直接复用；下载成功而导入失败时不会反复换源重装。
- 桌面 Qt 运行依赖固定为 6.11.2。空环境全量曾在 6.12.0 的 PySide DLL 退出时访问冲突，即使测试断言全通过也不算验收成功；最终复验结果以发布验证报告为准。
- 轮次截止时间使用整数纳秒计算，消除嵌套时间预算的浮点边界误差；保留过期前拒绝调用模型的原有规则。
- 研究假设、决策、分支和任务经验使用独立编号。修复同毫秒创建时的主键碰撞，以及不同动作经验被静默覆盖；原有记录、权限和验证等级不变。

## 实际验证的边界

协作功能前一阶段已有 17 次真实 Luna 调用，包含群内汇报、私聊主账号、既有智能体邮箱、自动选择及三机器人多层分工。详情见[协作汇报与多层流程](协作汇报与多层流程_20261112.md)。本次打包阶段没有额外向真实 QQ 发送测试消息，没有调用 Claude，没有注销或切换 QQ 账号。

本机完整套件、安装器及独立 Windows 沙箱的最终结果随发布包提供《发布验证报告》。测试替身、真实组件、真实模型、QQ 收据、首次安装与实体设备分别记录；不能把测试数量换算为所有功能、模型、设备均可用。

Windows Sandbox 是本机创建的独立 Windows 环境，本次不把它称为云主机。Mac、Linux、APK、实体手机、任意模型组合、多日无人值守及自动建群不因本次 Windows 打包而获得新的验收结论。已知问题仍以 [KNOWN_ISSUES.md](KNOWN_ISSUES.md) 为准。

## 使用发布包

- 新电脑优先运行“一键配置启动器” EXE；它包含程序和环境准备工具，首次缺少依赖时需要联网。
- 已有用户更新时请选择原安装目录，继续使用原目录的数据和登录配置；新建目录不会自动拥有你的私人账号资料。
- 绿色包须完整解压后运行 `Open QQ Dot.exe`，不能单独拿走其中的薄启动 EXE。
- 源码包包含开发代码、测试和公开文档，排除私人好友、账号登录、密钥、数据库、聊天记录、工作区及模型权重。
- 本地模型权重按需下载，共享相同权重；权重共享不意味着好友记忆、向量集合、配置或权限共享。
- 个人 QQ 直连的可选运行时未随本安装器预装；已有运行时与登录态仍使用原来的本机目录。

可选运行依赖：[msvc-runtime](https://pypi.org/project/msvc-runtime/)。其微软许可证随下载的包保留，不由本项目的 GPL 重新授权。
