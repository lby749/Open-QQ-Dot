## 数据与权限边界

### 好友经验隔离已修复，旧账目没有被自动迁移

曾发现经验页面在当前好友标题下使用全库查询，候选经验又默认归属 `user`。当前修复使服务缺少 owner 时拒绝，摘要的总数/状态/列表及全文检索、中文回退均在 SQL 中限定 owner；两个桌面调用者传入当前好友，切换时清理原好友尚未提交的输入。

HTTP 经验接口还验证设备令牌、`tasks:read` 和已授予的好友范围；匿名旧本机模式不能读经验。全局管理员读取仅由非空管理员令牌的可信认证结果开放，请求体或查询里的 `admin=true` 无效。历史 `owner='user'` 不会被自动分配给任意好友，原记录保留；其他好友的共享标志也不使桌面私有视图自动串库。

17项专项验证使用合成数据库、虚构设备、真实本机 HTTP 和 Qt，没有读取真实用户数据库或调用真实模型。原测试中复制开发者真实经验库/签名密钥的夹具已改成临时合成库。

### 旧版 HTTP API 仍有兼容边界

经验接口和手机协作接口的严格 owner/scope 检查，**不能证明所有旧 HTTP 路由具有同等范围的隔离**。本轮补齐好友令牌的任务、审批、通知与研究归属检查；没有 owner 绑定的旧健康概览拒绝普通设备访问，保留显式管理员访问。相关受限 HTTP/SQLite 专项通过，但仍未对每条旧路由完成同等程度的审计。

BETA 不将旧服务当成可任意暴露公网或共享给不可信设备的多租户接口。只读不等于不敏感，任务标题、账号目录与路径也可能包含私人信息。部署时应保持受限网络和可信认证；遇到需要向第三方共享设备访问的场景，应先核查具体路由，不以“已配对”代替所有操作的授权。

### 宿主权限与发布隐私

程序有项目路径、好友身份、只读/读写、命令审批和敏感路径检查，但同一操作系统账户下运行的不可信宿主代码仍可能访问同账户资源；这不是操作系统沙箱。

日志、聊天导出、诊断包、胶囊、研究输入快照和截图都可能含私人内容。源码发布过滤不代表这些单独导出的文件已经脱敏。不得发布真实 `data/`、`friends/`、QQ登录、令牌、证书私钥、模型会话和工作区；公开合成示例也不能冒称真实聊天。

## 结果质量与稳定性限制

- **检索指标不可混用。** 同一已知对话的自恢复命中、语义相关性、人设遵循、自动模板选择与真实任务成功率是不同目标。高命中率不能替代后者；部分保留集仍有漏召回。
- **中占用已知回退已修复，泛化仍有边界。** 原15条固定改写中，完整检索首位命中由13/15恢复为15/15；另20条事先固定的人工改写及另一种子的30条已知查询，在三档真实模型上均未出现新回退。修复保留召回与重排的一致性，只调整示例排序，未放宽原始得分门槛。这不是开放域相关性或实际任务成功率的证明，详见本机阶段记录（原始测试材料不随公开包提供）。
- **人设不是确定性规则引擎。** 配套例句接入不保证每个模型永远遵循风格；模型可能重复问句、过度安慰或偏离设定。应以实际对话质量核查，不用机械词汇评分制造“全部自然”。
- **保留已发现的回复质量失败。** 一次真实 Luna + 个人 QQ 收发中，模型完整复用了合成例句并带入示例里的物品信息；发送及回执通过，自然度未通过。单次新场景复核不能消除这条失败，也不能证明所有模型均不照抄示例。
- **运行查询不全知。** `inspect_runtime` 返回允许公开的当前配置；不同后端专用模型/档位字段覆盖仍不完全，不是在线模型探针，也不是全盘配置浏览器。
- **未知副作用不会自动重放。** 实验或发送有收据但结束未确认时，恢复会等待核查。这可能需要人工处理，是防重复执行的边界。
- **旧研究预算无法完全追溯。** 新账本增量计费且保留旧预算基线，基线之前的漏计、重复记账或不准确估算不能重建；含估算的用量不是供应商账单。
- **协作仍消耗真实资源。** 主持、成员、验证、工具调用与重排都有成本；减少重复上下文不等于原生 CLI 系统提示和内部请求消失。部分 CLI 只能限制启动次数，不能精确限制其内部所有 API 请求。
- **有限静态自审不是全面安全与 SEO 检测。** 不支持的语言、动态页面渲染、线上 HTTP、认证业务逻辑、依赖漏洞和搜索收录仍需专项核查。
- **布局测试有尺寸范围。** 已修复单页多余切换、QQ双层滚动、窄任务页和历史滚动；连接方式改为横向切换，公共切换条增加留白，顶部好友/连接状态在宽度不足时换行。已检查 1050/1180/1460 宽度及 150% 缩放的相关 Qt 组件，不能保证所有缩放、字体和屏幕组合均无缺陷。

## 安装与测试声明

Windows 薄启动 EXE 要与发布目录中的源码/资源配套使用；不要只复制单个启动 EXE。安装器按需准备缺失运行环境和依赖，可选模型与 QQ 运行时不是全部预装。复用缓存、隔离目录、限制 PATH、容器以及全新操作系统，是不同基线，报告必须说清楚。

BETA.3 已在本机新建的独立 Windows Sandbox 中确认初始没有 Python、没有应用目录，实际完成基础环境下载、启动依赖检查、覆盖修复及 CPU 向量环境导入。这是本机干净 Windows 环境，不是远程云主机，也不是所有用户电脑的证明；最终快照的完整首装、套件、包哈希、数据保留及窗口启动结果以随包《发布验证报告》为准。Windows C++ DLL 作为应用内运行依赖准备，不安装系统级运行库；早期依赖外部安装器的失败也保留在报告中。云端、真实 QQ、手机与付费模型账号必须分别核查，不能由安装成功外推为全部通过。

历史全量运行出现过失败，相关项已定向修复；不能将后续定向通过改写成当时全量零失败，也不能以测试数量代替实际体验。当前已通过的专项及证明层级见 [FEATURES.md](FEATURES.md)。
