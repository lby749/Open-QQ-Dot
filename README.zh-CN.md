# Open QQ Dot · BETA 测试版

**把你在 QQ 里提出的需求，变成能规划、执行和检查结果的工作。**

Open QQ Dot 是运行在自己电脑上的中文自主智能助手。它既能按好友的不同人设陪你聊天，也能接下实际任务：拆步骤、使用获准的工具、生成文件、检查结果，并把进度告诉你。桌面是统一管理入口，QQ 用来交流和交办，配对的蓝色安卓应用让你在手机上查看任务和参与协作。

## 能帮你做什么

### 不只回答，也能做事

在工作台写清目标，或者直接在 QQ 中交办。智能体可以把任务拆成步骤，在你允许的范围内操作网页、处理文件和执行本机工作。计划、执行情况、结果和验收记录都有入口，方便你确认它到底完成了什么。

聊天和做任务分别处理。普通聊天按好友的人设与回复方式表达；任务中的进度和结果可以自然汇报，完整诊断保留在任务界面，避免把内部记录整段发给对方。

### 多个智能体可以分工，而不是只能顺序轮流回答

你可以编辑带有多个入口和分支的协作流程，为节点选择智能体、可用模型、思考强度和职责。入口可以对应工作台、某个好友私聊或已有 QQ 群。关掉一个节点时，后续分支一起停用，配置仍然保留。

成员可以在群里汇报、私聊汇报，或通过内部邮箱交接，也可以自动选择。协作配置和运行记录分开显示：一边安排怎么工作，另一边查看谁接了什么任务、交给了谁、结果有没有回来。已有 QQ 群可由当前主账号配合多个官方机器人参与；自动创建新群目前暂缓。

### 长任务分阶段推进，成功经验可以复用

为长期目标和研究任务设置阶段、检查点、预算与停止条件，保留进度、产物和研究记录。你可以在中途检查、调整或继续任务。完整科研闭环与多日无人值守仍在验证，不能把一次成功当作长期可靠性的保证。

已经验收的成功任务及你的纠正，可以整理成可编辑的工作流。任务胶囊用于保存、查看和复用任务材料。普通聊天不会全部当成成功经验，模型自称完成也不能代替结果验收。

### 每位好友可以有不同的相处方式和权限

分别设置人设、关系、回复偏好、记忆和工具权限。快速配置提供配套的说话风格与对话示例，也可以自行调整常驻指令或导入模板。切换好友时，页面应跟随当前好友更新。

各好友的记忆、任务和权限分别管理；相同模型文件可以共用，避免重复下载。没有权限的操作会明确拒绝，拒绝时怎么说也可以编辑。

### 电脑管理，QQ 交流，手机参与

桌面控制台集中管理任务、好友、模型和协作。蓝色安卓应用配对后提供移动入口；QQ、电脑和手机支持消息同步。手机端依赖电脑服务，电脑需要保持运行，远程访问还需要完成网络配置。

控制台支持语音输入：**点一下开始录音，图标变为停止；再点一下结束并转写。** 文字只进入输入框，由你确认发送。小型识别模型自动下载、后续复用，不放进安装包；也可以在语音设置中选择其他模型。

### 模型和工具由你选择

统一管理已接入的模型和外部智能体，为不同成员设置合适的模型、思考强度和工具权限。模型列表会根据具体工具提取；是否能调用仍取决于你的账号、授权、额度和服务状态。界面中的模型名称不代表每一种组合都已经实测。

## QQ 怎样连接

首次默认使用 **官方 QQ 机器人**，在连接页填写自己的机器人资料，并按 QQ 平台允许的场景使用。官方机器人和个人账号方式分别配置，也可以同时在线。

原有入口保留为 **个人 QQ 账号直连（NAPCAT）**。使用自己的 QQ 账号。有风险。

发布包不含开发者的账号、密钥、聊天或登录资料。本项目与腾讯没有隶属关系。

## 使用前请了解

- 这是测试版。语音通话、完整科研与论文流程、连续多日运行、全部模型组合和实体手机仍有未完成或未验证部分，见[当前限制](docs/KNOWN_ISSUES.md)。
- Windows EXE 当前未作商业代码签名，安卓沿用已有测试签名。macOS / Linux 提供[源码启动说明](docs/macOS与Linux源码启动_20261026.md)，尚无经过实机验收的原生安装包。
- 资料在本机管理；选择云端模型时，完成请求所需的内容仍会发送给所选服务。不要向不可信的网络公开应用入口。
- 自动配置会复用有效资源，按需下载依赖和模型；不包含全部离线环境。首次安装、登录和网络授权仍需要满足相应条件。
